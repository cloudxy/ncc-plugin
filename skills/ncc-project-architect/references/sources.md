# 架构方法来源

2026-10-19核对原始在线页面。SOP/模板由NCC自写，方法不引入工具链、外部技能或运行依赖。

| 来源 | 使用时机与NCC转化 |
|---|---|
| [C4 model：图的层次](https://c4model.com/diagrams) | 说明边界与依赖时选择能回答问题的图层，配合代表读写链；不强制每次画所有层次。 |
| [ADR社区：架构决策记录](https://adr.github.io/) | 有关键取舍时记录背景、方案、决定及后果；NCC模板增加当前授权、迁移验收与反转条件，不复制某个上游模板。 |

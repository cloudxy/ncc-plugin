# 拆书学法与写作转化

L3 只读取 `decon packet <拆书库> --layer L3` 给出的已验报告/事实/场次白名单，核对指纹。不读取原文，不把原文路径转交执行者；原文阅读只发生在 L0/L1 的机械处理和 L2 已选章抽取。

输出只包含方法模块：method、applies、cost、invalid_when、evidence。证据逐条为 artifact（包内相对路径）、可选 record_id 与 locator（该报告中5–15字连续定位词）；至少两处独立证据；同一个产物无 record_id 时只能算一处，同产物不同场次/事实须明确 record_id。重复引用不计两处。不搬运人物、事件链、对白或本书正文。`decon ingest <库> <方法文件> --layer L3` 验收后仅写拆书库报告，不写作者大纲。

一处证据仍只是样本，两处以上才写技法；保留适用条件、代价和失效。抽样研究不强等30–50连续章，但先满足计划覆盖；完整拆解仍按段/卷学法。可用已有 technique add/check/match 接口写卡，字段与类别沿用现有技法库，不另建卡片状态系统。

对标场景只作为参考留在拆书库；作者决定采用后仍由 outliner 规划、story-editor 审故事、writer 按本书派单包写作。不能把对标书场次直接复制进作者场景卡。

# 拆书派单包与跨章三件套

L2 包绑定索引、章 hash、计划、总纲文件、词表和上下文来源。执行者只读本章 span、指定总纲与包内材料；已有实体使用库内 ID，新实体留空并给专名/局部引用标识 local_id。长章分块时传递已抽实体清单，不重复猜身份。

三件套是前情摘要、活跃实体/别名、未回收伏笔；必须有内容，或有来源和理由的空集合。首章允许初始化空集。紧邻前章已有可信验收结果时可据其及前缀台账构包；非连续样本不拿上一抽样章冒充前章。

缺可靠上下文时阻塞跨章抽取；作者明确接受章内独立分析可加 --independent，成果留章文件，不能进入跨章实体/关系/状态/伏笔事实台账。不得为补上下文隐含扫全书；新增阅读范围单列成本和授权。

手工 --context 文件的 previous、entities、foreshadows 各为对象，包含 value 与 source:{path,sha256,observed_through}；空值再给 empty_reason。source 是拆书库内已存在的摘要/台账/报告，指纹必须匹配。unread 明示中间未读范围。包自身、当前章成果不能反向当作前情来源。

原文、总纲、词表或来源变化后重新构包；不修改旧包指纹冒充新输入。执行者只提交章 JSON，经理通过入库接口记账。

显式上下文每项 source.observed_through 必须小于本章 seq；previous 必须观察至 seq-1。本章、未来章或本包不能反向充当前情来源。若可靠上下文需补读，先在计划中声明阅读范围和成本。

# 写手方法（writer）

写手只照**写作简报**写（`writing-brief.md`），不照考核清单写。v0.2 放在这里的工艺清单（张力波峰数、对话占比、转折数、开头技法、欠·挣·超·证自查）已移到审稿侧，成为审稿者的诊断工具（`../../ncc-review/references/review-domains.md`），写手不读。

## 怎么写

1. **先读简报，再读声音。** 上下文包的阅读顺序是：写作简报 → 读者此刻 → 出场人物的声音样例 → 可用材料 → 前一章结尾原文 → 文风基准。动笔前最后读的必须是正文语态。
2. **从视角人物的身体写起。** 他看见、听见、闻到、碰到什么；他不知道的事，叙述也不知道。
3. **把两难演出来。** 让人物在压力下做选择，用动作、对话和代价显出选择的分量；不让任何人（包括叙述者）说出这场的意义。
4. **绕开简报里列出的"最容易想到的写法"。** 判断标准：意料之外，情理之中——读者没猜到，但回头一看，前面都有铺垫。
5. **一个画面。** 全场围着简报给的那个画面蓄力，让它出现在最该出现的地方。
6. **先写后删。** 写完删三类句子：解释情绪的（"他感到一阵愤怒"）、复述前情的、结尾点题的。删完如果某处空了，用动作或物件补，不用解释补。

## 发散—收敛（关键章的关键节拍）

简报里标了"本节拍写 2–3 个版本"时：

1. 先在草稿区写下这个节拍**最容易想到的三种走法**（各一句），然后都不用。
2. 写 2–3 个走法彼此不同的版本（不是同一走法换措辞），每版一段到一场。
3. 各版本存到 `04-正文/_versions/ch-NNNN-<节拍>-A.md` 等，交回经理。**不要自己挑**——比选是审稿与作者的事（成对比较＋作者定稿，见 review-domains.md 品质层）。
4. 作者选定后，把选中的版本接进正文，其余版本保留存档。

常规章不做发散；成本按常规章与关键章约 8:2 分配（D8）。

## 写完之后：回写三本账（写手每章必做）

写的时候不想台账，写完再回写：

1. **承诺台账**：本章新建的承诺 `promise add`，推进的 `promise touch`，兑现的 `promise resolve`；低成本埋下的含义开放细节记为 `--type 期权`；反复出现的核心意象记为 `--type 母题`（再次出现时 `touch`）。
2. **知情台账**：新的信息差 `know add`（写清 known-by／unknown-to）；角色得知真相 `know learn`。
3. **世界账**：新出现或引用的距离、物价、称谓、历法、数值——先 `fact get` 查，有就照用，没有就查资料、注明出处后 `fact set`，拿不准的不写具体数字（宁缺律）；人物状态变化追加到状态事件（entity/chapter/attribute/old→new/reason/evidence 定位词）；**主角失去了什么，记 `attribute: 失去`**。
4. **章节**：`chapter hook`（章尾钩子类型与强度）、`chapter mood`（压／放／平，加情绪色）；开篇章落地的签约点用 `sign`。
5. 设定词典「首现章计划」→ 实值修正；新专名先查词典，没有再登记。
6. `current-focus.md` 更新为下一章焦点。

**宁漏勿错**：没有原文依据的内容不回写；不确定的标「待定」。回写的数据是下游审稿与"读者此刻"的输入，污染一处、误导全书。

## 修订纪律（被打回时）

- 只改硬伤层 observation 指出的问题＋其直接牵连处，不做全文重写（除非场景卡级打回，那要先改场景卡、重过故事审）。
- 每轮修订在文件尾注一行：`rev N: 依据 ch-XXXX-review 修改 {要点}`。

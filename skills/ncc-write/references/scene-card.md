# 场景卡（先审故事，后写文字）

**一章 1–3 张场景卡，过了故事审才写正文。** 故事问题（这场没有翻转、选择不难、情感不对、风险没升级）在场景卡阶段发现最便宜；写成正文再改，最贵（D14）。

设计来源：麦基《故事》——每一场都让人物处境中的某个价值发生翻转，不翻转的场景就是没发生事；Swain——目标、冲突、挫折／反应、两难、决定；oh-story——细纲写"本章必须发生什么变化"，过结构验收才写正文。

## 什么时候写、谁写、谁审

- **即写即做**：场景卡只提前做到下一章（最多下一个单元的关键章），不为 50 章滚动窗做场景卡——那会过度规划，也和园丁、混合模式冲突。
- **起草**：outliner（task: scene），依据章纲、承诺台账、"读者此刻"、人物卡。园丁模式下章纲可以没有，outliner 直接从上一章结尾和人物欲望推出本章场景。
- **故事审**：story-editor（task: story-review）。常规章由它审，结论按推荐执行、记为暂定，单元复盘时作者复看；**关键章的场景卡须作者过目**（与关键章工序一起，在单元设计时集中批）。
- **登记**：`ncc_state.py scene check <书目录> <章号>` 校验格式；`scene review … --result pass|revise --by story-editor|author` 记结论。场景卡在审过之后被改动，脚本会要求重审；没过故事审的章不能标 drafting，也不能 complete。

文件：`02-大纲/场景卡/ch-NNNN.md`。

## 模板

常规章（每场至少五项，三五行即可）：

```markdown
## 场景 1
- 视角：<人物>
- 目标：<他在这场要什么>
- 翻转：从「……」到「……」
- 两难：A（代价……）还是 B（代价……）
- 情感：<读者该感到什么，可用调色板：爽、燃、虐、甜、怕、笑、悲、敬、叹；压／放>
```

关键章（每场九项全写）：

```markdown
## 场景 1
- 视角：<人物>　盲区：<他此刻不知道什么（知情账）>
- 目标：……　阻碍：……
- 翻转：从「……」到「……」（人物处境里的哪个价值变了：安全↔危险、尊严↔屈辱、信任↔背叛……）
- 两难：A（代价……）还是 B（代价……）——两个都不完全对
- 情感：……（以及余味：读者合上书还剩下什么）
- 画面：全场只要一个让人记住的画面
- 风险：比上一场高在哪里
- 关键节拍：<这一场里要写 2–3 版的那个节拍：开场、转折、兑现或章尾>
- 本场必须发生：<来自章纲与承诺义务的事件>
```

## 故事审清单（story-editor 用，写手看不到）

| 问 | 不通过的样子 |
|---|---|
| 这场翻转了什么？ | 场景开始和结束时，人物处境没有任何变化（文学层面的水章） |
| 两难是真的吗？ | 一个选项明显是对的；或者主角根本没得选 |
| 目标情感清楚吗？ | 写着"紧张"，但事件本身不紧张 |
| 风险升级了吗？ | 和上一场同一个量级（对治 AI"事件升级平淡"的倾向） |
| 人物的欲望和需要在场吗？ | 人物只在推动情节，看不出他自己想要什么 |
| 意料之外，情理之中？ | 读者能提前猜到走法；或者意外但没有铺垫 |
| 有没有一个画面？ | 全场只有对话和动作，没有一个能截图的瞬间 |
| 大事溯因到人了吗？（主体性） | 局势变化没有落到某个具体的人、某个具体的决定上 |
| 结构约束在场吗？（主体性） | 人物想做什么就做成什么，看不出他手里有什么牌、缺什么牌；或者反过来，只见制度不见人 |

每条不通过都给**推荐改法与理由**（guidance 问题卡格式），不只说"不行"。

## 两道水章判据

- **连载层面**：本章没有建立、推进或兑现任何读者向承诺 → `check_chapter.py` 判不过。
- **文学层面**：本章任何一场都没有价值翻转 → 故事审不通过。

两道都要过：只还账不翻转，是流水账；只翻转不还账，读者会觉得在绕圈。

# 资料的整理、完善与创建

资料可以是现实知识、观察经历、图表名录、研究记录、写法参考，也可以是原创虚构的灵感素材。按内容特点组织，不强制压成一到三句的生活素材卡。

## 资料整理

先理解现有分类和用途，再决定调整的粒度。交付整理过的内容本身，而不只给重命名方案。

- 长篇混合笔记按主题拆分，但让论述、表格和解释保持完整；一组等级对照或完整工序可以作为一个整体。
- 完全相同的内容可共用一份整理成果，同时记录全部来源；有细节差异的内容逐项比较，留下独有信息和不同观点。
- 名称有异写时建立规范名与别名；同名不同对象不合并。分类可增设，不要求套用某种题材的分类表。
- 把概念、上下位、关联和使用条件写进内容；让作者能从主题找到需要的资料，再回到原文。
- 保留来源原貌与整理解释之间的区别。原资料错了可以指出、补证，不能悄悄把改后的版本冒充原话。

常见成果为专题文档、实体条目、关系索引、对照表、来源表。由资料规模选择组合，不要求每个主题重复生成所有文件。

## 资料完善

从目标和已有资料找具体缺口：概念不清、关键环节缺失、缺少适用年代或地域、缺反例、资料过时、数字无来源、结论与证据不一致。

对每个缺口确定补充路径：先从已登记资料恢复，必要时查证外部来源，最后把结论整合进相关文档。补充后说明新增了哪些信息、修正了什么、仍有什么不确定。

现实事实的查证遵守当前宿主的浏览要求。优先原始文献、官方资料、当事记录等直接证据；多个来源有分歧时交代分歧与适用边界。记录来源标题、作者或机构、地址/书目信息、定位以及查询日期。不能创建不存在的出处、调查经历或访谈原话。

不方便查证的事实标为推演或待核，登记具体问题；纯粹增加篇幅和空泛概述不算完善。

## 资料创建

先判断作者要的是哪种产物。上下文已清楚就直接做，只有会改变事实性质时才询问。

### 专题事实资料

例：为悬疑创作建立港口货运资料，或整理某时代城市生活。先列关键研究问题，再搜集出处、提炼内容、组织专题，形成能回答创作问题的资料包。原始材料可以新搜集，不要求用户先提供。

建议组织为：主题范围与适用条件、核心知识、流程或关系、具体例子、容易混淆之处、可能的创作用途、来源与待核项。按题材需要取舍，不强制每项都有。

### 原创虚构素材

例：创建一批虚构行业黑话、地名、民俗、人物遭遇、物件和社会机制。结合作者的风格与限制写出有差异、可调用的内容，每组解释适用场景或构思方向。明确标为原创虚构，来源可以是作者种子和创作约束，不需要伪造现实文献。

原创素材尚未被某个世界采用时，不擅自给它添加“本书官方设定”的身份。资料可以先创造，故事稍后再选。

### 推演或混合资料

真实知识加假设推演时，把已知事实、假设、推演过程和虚构部分分开；必要时拆成互相引用的成果。不要将整个混合文档登记为已核事实。推演不能自动晋升为事实。

## 通用资料条目的写法

以一个完整主题为单位，按需保留：

```markdown
# 主题名

适用范围与性质：真实资料 / 原创虚构 / 待核推演

## 内容
完整说明、条目或表格；单位、前提和例外就近交代。

## 关联与用途
与什么内容相关，可能帮助作者处理什么问题。

## 来源与尚未解决的部分
来源位置；哪些内容是推断，哪些仍缺依据。
```

以上是写作提示，不是要求复制的空表。正式交付须把实际内容写完；准备状态与采用决定由脚本维护，不在多份文档里各写一套互相竞争的状态。

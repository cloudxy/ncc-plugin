# 设定的整理、完善与创建

设定规定某个虚构环境里成立的事情。范围可小到一个人物或地点，也可大到共享世界、社会制度、能力体系。根据用户希望建设的规模工作，不要求已经有完整故事。

## 设定整理

先辨认现行口径、候选、旧版、通用素材和已写事实。已有作者决定优先沿用，并保留出处；文件更新时间不能代替采用决定。

整理分为三个层次：

- **体系**：整个环境怎么运行，哪些基本条件限制其他设定。
- **实体**：人物、组织、地点、物种、职业、技术、物件等具体内容。
- **关系**：上下位、因果、依赖、控制、交换、敌友、时间与认知差异。

建立有意义的分类和入口，把散落的同一设定组装完整。原文重复可归并，互斥内容须列出具体差异。时间不同、适用对象不同、公众说法与真实情况不同，可能是合理设计，应保留条件。

一份素材可以只采用某几个字段，其余搁置或排除。解释本次改编适用哪个世界或作品，避免改写通用库。多个作品共享世界时，区分共享规则与作品局部设定。

## 设定完善

以现有设定和创作目标为基准，寻找会影响使用的缺口，并实际补上相应内容：

| 检查方向 | 要问的问题 |
|---|---|
| 定义与边界 | 这个概念指什么，不包括什么，适用于哪些对象与时期 |
| 条件与过程 | 如何出现、获取、运行、改变或终止 |
| 资源与代价 | 依赖什么，有什么稀缺性、成本、限制与后果 |
| 关系与影响 | 会改变谁的选择、处境、资源和社会秩序 |
| 数量与时间 | 必需的单位、尺度、时间线和交换关系能否同时成立 |
| 例外与失败 | 谁能例外，凭什么；失败时发生什么 |
| 认知与揭示 | 真实情况、角色认识、公众传闻是否需要区分 |

不把所有方向强制用在每个对象上。人物更关注目标、矛盾、行动能力和关系；社会制度更关注权力与利益；科幻技术更关注能力边界与影响。没有超自然力量的作品不生成境界、法宝或丹药表。

补充时给出与已有约束相容的具体内容。遇到两条已定规则冲突，先列影响与可行修法；关键取舍由既有授权决定，不能靠悄悄删除其中一条解决。

## 设定创建

用户可以只给一句想法。先提炼已给的条件与想保留的体验，确定本次创建的是完整世界、一个体系还是若干实体。对方向性选择给有区别的方案与推荐；方向已明确或作者授权自由发挥，就直接创建。

通常按以下因果展开，已有内容可跳过：

1. **起点**：核心特征、环境条件、风格和不可违背的约束。
2. **运行机制**：世界或体系怎样运作，规则之间怎样连接。
3. **实体与关系**：哪些人物、组织、地点或物件让规则具体可见。
4. **使用验证**：在正常使用、边界情况和失败情境下推演，补上断开的因果。
5. **扩展接口**：哪些已定，哪些可继续发展；后续创作需要什么才补什么。

先创造一个能运作的完整范围，再按用户目标扩展。不要只给设定提纲和空卡，也不要未经请求就编整本大纲或正文。短情境推演用于检验规则，不当作已发生的剧情。

新设定必须明确是创作，而非“从资料里发现”。借鉴现实规律或参考作品时保留依据，改成独立的规则、关系和表达。作者已决定的角色身份、世界底层规则等不能被方便的创作替换。

## 通用设定的组织

具体结构跟随对象选择。可采用：核心定义、运行规则、条件与限制、实体、关系、变化与例外、可调用表现、来源/创作依据、待定项。

例如“沿海城市治理体系”可写议事、税收、港口控制与组织利益；“家庭关系”可写各人的目标、资源、旧事和日常互动；“共享奇幻世界”可写世界条件、文明、技术/魔法、生态和历史。不要把其中一种当作所有题材模板。

检查要用实际内容回答问题。填满字段不能证明设定完整，“一切由某种能量解释”也不能代替因果链。把无法确定但不影响当前范围的内容登记为有触发条件的待办；会影响当前结果的内容继续完善或明确呈给作者决定。

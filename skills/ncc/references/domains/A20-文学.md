# A20 文学

> 庚·表达｜读者：scholar（据此出本章知识点清单）、continuity（查硬伤）、outliner 与 story-editor（适用场景）。写手不读本卡，只拿 scholar 给的本章知识点。

- **核心洞察**：经典不是爽文的反面，是爽文的祖宗。《基督山伯爵》是教科书级的复仇爽文；《水浒传》的"逼上梁山"是被压迫者主体性觉醒的母题；《三国演义》是群像与智斗的宝库；《红楼梦》是人情冷暖的百科；《西游记》是关卡结构与团队配置的原型；《史记》用"互见法"（一个人的短处写在别人的传里）立体写人。经典能留下来，是因为抓住了人性里不变的东西。
- **适用场景与写法**：借结构、借母题、借人物原型，不借故事（与作者"只参考结构长处，不照搬剧情"一致）；从经典里偷"情感的深度"——爽文的爽是短的，经典给的余味是长的。
- **工具**：母题库（复仇、逆袭、背叛、守护、救赎、成长、寻找）；经典人物原型对照（诸葛亮型军师、宋江型领袖、王熙凤型管家……）。
- **典型硬伤**：去掉题材外衣后找不到任何母题；只读网文，写出来是"网文的网文"——同质化的根源。
- **诊断问句**：这一卷去掉题材外衣，讲的是哪个人类永恒的故事？
- **底书**：四大名著（《水浒》读金圣叹评本）；《史记》；大仲马《基督山伯爵》；金庸作品。

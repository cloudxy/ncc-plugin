# A24 宗教·神话·民俗

> 辛·想象｜读者：scholar（据此出本章知识点清单）、continuity（查硬伤）、outliner 与 story-editor（适用场景）。写手不读本卡，只拿 scholar 给的本章知识点。

- **核心洞察**：神话是一个民族解释世界起源和秩序合法性的方式；宗教组织同时是信仰组织，也是权力组织和经济组织（寺产、香火、信众）；民俗与禁忌是恐惧和经验的化石——每一条"不能做"背后，都有一次曾经的灾祸，或一种需要维持的秩序。
- **适用场景与写法**：诡异文的规则与禁忌（规则怪谈的根）；洪荒与神话再造（封神的"劫"与"榜"，就是制度化的神权分配）；神权与王权之争作争霸暗线。
- **工具**：禁忌卡（禁忌／起源／违反后果／谁在维护）；神系—人间势力对应表。
- **典型硬伤**：神话元素只堆名号而无秩序（作者对西游、封神吸收的是"结构性关卡、名号感、神话大势压迫"，不是名号本身）；宗教只有神迹，没有组织和经济。
- **诊断问句**：这条禁忌最早是为了防什么？现在谁靠维护它得利？
- **底书**：《山海经》；袁珂《中国神话传说》；弗雷泽《金枝》。

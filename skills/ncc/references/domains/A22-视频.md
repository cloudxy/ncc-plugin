# A22 视频（影视与镜头语言）

> 庚·表达｜读者：scholar（据此出本章知识点清单）、continuity（查硬伤）、outliner 与 story-editor（适用场景）。写手不读本卡，只拿 scholar 给的本章知识点。

- **核心洞察**：今天的读者是被影视和短视频训练出来的，读小说时脑子里在"放片子"。镜头语言有语法：景别（远、全、中、近、特写）、镜头运动、剪辑节奏。库里肖夫效应说明**观众从画面的并置中读出情绪**：同一张脸，接一碗汤是饥饿，接一口棺材是悲伤。打脸爽的核心镜头不是主角出手，而是**反应镜头：围观者的脸**。
- **适用场景与写法**：名场面＝能截图的一帧（有构图、有对比、有象征）；打斗分镜（全景立空间→中景写动作→特写写代价→反应镜头写地位变化）；短视频"前三秒"逻辑对应黄金三章与章首；影视、短剧、动态漫改编友好度（画面感强、场景集中、冲突外化）。
- **工具**：分镜三问（先让读者看见什么？谁的脸需要特写？哪一帧能当封面？）；名场面卡（构图、光、声、反应）。
- **典型硬伤**：空间关系混乱；通篇对话没有画面；镜头只跟主角，没有反应镜头（打脸没人看见）；该跳切的地方拖沓。
- **诊断问句**：这一场拍成短剧，前三秒拍什么？
- **底书**：阿里洪《电影语言的语法》；麦基《故事》；默奇《眨眼之间》。

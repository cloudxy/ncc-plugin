# A16 工程

> 己·造物｜读者：scholar（据此出本章知识点清单）、continuity（查硬伤）、outliner 与 story-editor（适用场景）。写手不读本卡，只拿 scholar 给的本章知识点。

- **核心洞察**：工程是**在约束下取舍**：成本、时间、质量、安全不可兼得。系统产出由最窄的瓶颈决定（约束理论）；规模化靠标准化（秦代兵器部件标准化，并以"物勒工名"追责工匠）；战争打的是后勤。建成只是开始，维护才是长期成本。
- **适用场景与写法**：基建、种田、经营、军团流的核心爽是"系统跑起来"的掌控感；主角用工程思维（找瓶颈、搞标准化、建流水线）碾压经验主义对手，是高级智胜爽；断粮道胜过斩上将。
- **工具**：瓶颈分析；人—料—时估算（修一座城要多少人、多少天、多少粮）；后勤链图。
- **典型硬伤**：一夜建城；只写产出，不写维护和损耗；工业化跳过工具母机和人才培养。
- **诊断问句**：这项工程的瓶颈在哪？谁在干活，他们吃什么？建成后谁来维护？
- **底书**：高德拉特《目标》；《孙子兵法·作战篇》。

# A7 经济

> 丙·天下｜读者：scholar（据此出本章知识点清单）、continuity（查硬伤）、outliner 与 story-editor（适用场景）。写手不读本卡，只拿 scholar 给的本章知识点。

- **核心洞察**：价格是信息——它把分散在无数人脑子里的稀缺程度汇总成一个数字（哈耶克）。货币的本质是信用；通胀是悄无声息的财富转移。检验一个世界的经济逻辑只要一句话：**什么东西稀缺，谁控制它**。
- **适用场景与写法**：打破资源垄断；商战与经营爽；主角的金手指一旦能量产稀缺物，就会冲击价格体系，二阶后果自动生成敌人和盟友。
- **工具**：本书物价表（米、盐、铁、灵石、丹药、功法的相对价格，全书统一）；米价温度计（每卷记一次，米价就是治乱）；资源流向图（与 A3 共用）。
- **典型硬伤**：灵石无限、物价不存在；主角暴富而市场毫无反应；货币与发行者的信用无关。
- **诊断问句**：主角这笔钱花出去，谁赚了、谁慌了？
- **底书**：亚当·斯密《国富论》；哈耶克《知识在社会中的运用》；彭信威《中国货币史》。

# A17 建造（建筑与城池）

> 己·造物｜读者：scholar（据此出本章知识点清单）、continuity（查硬伤）、outliner 与 story-editor（适用场景）。写手不读本卡，只拿 scholar 给的本章知识点。

- **核心洞察**：建筑是权力、信仰和生活方式凝固下来的样子：宫城中轴对称是秩序宣言，山门与台阶的高度是让人仰视的心理设计，城墙的厚度写着这座城怕什么。中国古建以木构为骨、斗拱榫卯为节、夯土为基，所以"墙倒屋不塌"。城市有规划母题：《考工记》"匠人营国，方九里，旁三门……左祖右社，面朝后市"。城防是一套系统：护城河、城墙、马面、瓮城、城楼，各司其职。
- **适用场景与写法**：守城流（作者的"守住一线"）的真实感来自工事细节；宗门、皇城的空间气势是名场面的舞台；建设者爽——从草棚到城池，每一次升级都看得见。
- **工具**：关键场景平面图（入口、高低、视线）；城防系统清单；建筑与文明程度匹配表。
- **典型硬伤**：场景没有方位感（读者不知道谁在哪）；建筑风格与时代不符；攻城只写冲锋不写工事。
- **诊断问句**：从大门走到大殿要经过什么，是仰视还是平视？这座城最薄弱的一面在哪？
- **底书**：梁思成《中国建筑史》；李诫《营造法式》；《考工记》。

# A8 军事

> 丙·天下｜读者：scholar（据此出本章知识点清单）、continuity（查硬伤）、outliner 与 story-editor（适用场景）。写手不读本卡，只拿 scholar 给的本章知识点。

- **核心洞察**：战争是政治的延续（克劳塞维茨）；胜负多半在开战前就定了——"多算胜，少算不胜"；仗打的是后勤、组织和士气，个人勇武是放大器，不是底数。"日费千金，然后十万之师举矣"：打仗首先是烧钱。**超凡世界的核心军事难题**：个体战力极高时，军队还有什么用？剧情一旦写到超凡世界的战争，就必须回答（阵法合击、战争器械、凡人军队的后勤与占领职能、强者之间的相互牵制与盟约）。
- **适用场景与写法**：以少胜多、奇谋、断粮道、守城；主角从"一人之勇"到"统帅之能"，本身就是一次升维。
- **工具**：兵力—粮草—距离估算；战役三问（为何而战、凭何而胜、胜后如何守）；超凡—军队关系设定表。
- **典型硬伤**：大军没有粮草、行军没有速度、士气不存在；强者一人可灭国，却仍然大规模征兵而不做解释。
- **诊断问句**：这支军队每天吃多少、从哪运来？打赢之后谁来守？
- **底书**：《孙子兵法》；克劳塞维茨《战争论》；《资治通鉴》战例。

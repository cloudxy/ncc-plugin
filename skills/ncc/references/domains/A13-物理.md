# A13 物理

> 戊·物数｜读者：scholar（据此出本章知识点清单）、continuity（查硬伤）、outliner 与 story-editor（适用场景）。写手不读本卡，只拿 scholar 给的本章知识点。

- **核心洞察**：自洽的根是**守恒**。能量、动量不会凭空出现或消失：一击的力量从哪来，打完去了哪（反冲、热、冲击波、地面崩裂）。任何秩序都要持续投入能量才能维持（熵增）——宗门、王朝、阵法、肉身都一样，停止供养就会衰败。**尺度决定现象**：同一条规律在不同尺度上，表现完全不同。
- **适用场景与写法**：力量体系的量纲（定义域与阈值，见本书力量体系的量纲表）；战斗的物理质感（音爆、反冲、脚下蛛网裂纹——"重"要被看见）；以巧破力（惯性、共振、支点）；熵增作为终极反派（末日、诸天衰亡）。
- **工具**：能量账（输入—输出—损耗）；阈值效应（量变到质变的临界点，就是突破）；尺度换算表。
- **典型硬伤**：音速拳却没有音爆和反冲；毁城一击却无余波；前后数值矛盾。
- **诊断问句**：这一击的能量从哪来、去了哪？出拳的人脚下发生了什么？
- **底书**：费曼《费曼物理学讲义》；伽莫夫《从一到无穷大》。

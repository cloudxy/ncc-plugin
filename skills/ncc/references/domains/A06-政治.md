# A6 政治

> 丙·天下｜读者：scholar（据此出本章知识点清单）、continuity（查硬伤）、outliner 与 story-editor（适用场景）。写手不读本卡，只拿 scholar 给的本章知识点。

- **核心洞察**：权力不是一个人的属性，是一张关系网——没有人能独自统治。统治者必须满足一小群关键支持者（将领、大族、宗门长老），他的每个决定首先是对这群人的交代。合法性有三种来源：传统、个人魅力、法理规则（韦伯）。所以政治的核心问题永远是：**谁需要谁，谁能替换谁**。
- **适用场景与写法**：权谋爽＝主角比对手更早看清联盟结构，拆掉对手的关键支持者，而不是正面硬拼；让反派不降智的最好办法，是让他被自己的联盟绑住（想退退不得）；朝堂戏写成利益交换，不写成忠奸辩论。
- **工具**：权力地图（每个势力的关键支持者、他们要什么、能被谁拉走）；韩非"法、术、势"三分（制度、手段、位置）；合法性来源表。
- **典型硬伤**：皇帝或宗主不受任何支持者约束；朝堂只有忠奸二元；政变时没写军队的态度；"大人物一句话，程序自动完成"。
- **诊断问句**：这个决策者做这个决定，要向谁交代？如果他的二把手反对，会怎样？
- **底书**：《韩非子》；马基雅维利《君主论》；布埃诺·德·梅斯奎塔、史密斯《独裁者手册》；《资治通鉴》。

# A14 化学

> 戊·物数｜读者：scholar（据此出本章知识点清单）、continuity（查硬伤）、outliner 与 story-editor（适用场景）。写手不读本卡，只拿 scholar 给的本章知识点。

- **核心洞察**：物质变化要**条件**：温度、配比、纯度、时间、催化，缺一个就失败，而失败有可辨认的症状（变色、结块、爆燃、有毒副产物）。古代炼丹术是中国化学的前身，火药就出自炼丹家之手；火候、提纯、升华这些真实经验，是修仙炼丹最好的质感来源。
- **适用场景与写法**：炼丹、炼器、毒术的专业爽（火候＝温控，配伍＝反应，丹毒＝杂质副产物）；种田流科技爽（写原料获取、提纯和失败次数才可信）；以化学破局（毒、火、烟、腐蚀）。
- **工具**：工艺卡四栏：原料／条件／步骤／失败症状。
- **典型硬伤**：一次就成功；原料凭空出现；写错化学常识（写不准就别写配比和温度）。
- **诊断问句**：原料从哪来，纯度怎么保证？第一次失败是什么样子？
- **底书**：宋应星《天工开物》；葛洪《抱朴子·内篇》。

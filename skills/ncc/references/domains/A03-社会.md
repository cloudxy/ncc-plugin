# A3 社会

> 乙·人间｜读者：scholar（据此出本章知识点清单）、continuity（查硬伤）、outliner 与 story-editor（适用场景）。写手不读本卡，只拿 scholar 给的本章知识点。

- **核心洞察**：社会是一台资源分配机器，外加一套让人接受分配结果的说法（合法性）。任何"看似不合理却存在"的规矩，背后都有从中受益、并且有能力维持它的人；它没被改掉，是因为改的成本落在无力者身上，收益却很分散。明规则之下有潜规则，潜规则靠"合法伤害权"执行（吴思）。**阶层流动通道**（科举、军功、宗门考核、资质测试）的松紧，决定一个社会的张力，也决定主角逆袭的难度。
- **适用场景与写法**：作者的"在制度压迫里硬生生撕开生路""用凡人起点打破修炼垄断"都要求先把制度写硬：剧情写到主角撞门槛、破垄断、碰潜规则时，这层结构得真实，撞开才爽。
- **工具**：资源流向图（钱、粮、灵石、功法从谁流向谁）；机制因果链（规矩→受益者→受害者→主角位置）；底层生计三问（吃什么、挣多少、怕什么）。
- **典型硬伤**：社会里只有主角和敌人两种人；底层没有生计；门槛只挡主角一个人；"大人物一句话，程序自动完成"（作者规则）。
- **诊断问句**：一个普通人在这个世界一天挣多少、一顿饭花多少？这条规矩要是废了，谁第一个跳出来反对？
- **底书**：吴思《潜规则》《血酬定律》；费孝通《乡土中国》。

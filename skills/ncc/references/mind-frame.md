# 创作思维框架（规划者与审稿者共用的最高判据）

与 `workflow/registry.json` 的 axioms 同源；冲突时公理优先。**写手不读本文件**——写手只读写作简报（`../../ncc-write/references/writing-brief.md`），本文件是经理、大纲、设定、发展编辑与审稿用的判据。

## 一、八条公理

1. 书魂先于情节，情节先于知识。
2. 一切叙事元素都是对读者的承诺（建立→推进→兑现）。
3. 决定按可逆度分层（L0 书魂 → L1 骨架 → L2 单元 → L3 章 → L4 文字），越难撤回越早定、越少人定。
4. 读者始终在场：写每章前先看"读者此刻"。
5. AI 扩展选项，人做选择。
6. 好钢用在刀刃上：常规章守下限，关键章投上限（约 8:2）。
7. 作者可持续。
8. 模糊之处给推荐，不把空白题丢给作者；推荐从作者种子里长出来。

**总分工：下限靠系统，上限靠作者与选择。** 系统保证不出错、不烂尾；出彩靠放大作者、给模型好材料和好提问，再在多个版本里挑。

## 二、小说家的生成模型（上限引擎用）

| 用在哪 | 模型 | 一句话 |
|---|---|---|
| 人物 | 欲望 vs 需要、恐惧、伤口、信错的那句话、内在矛盾、声音（Weiland）；典型环境中的典型人物（恩格斯） | 读者记住的是人。人物＝一个站在"世界的不公"里、用自己的方式回答主题之问的人 |
| 弧光 | 正向／负向／平弧 | 平弧主角信念不变、改变世界；信念要被一次次考验、付代价 |
| 场景 | 价值翻转（麦基）；目标—冲突—挫折／反应—两难—决定（Swain） | 不翻转的场景就是没发生事；两难要两个都不完全对 |
| 情感 | 读者的情感旅程（Maass）；调色板：爽、燃、虐、甜、怕、笑、悲、敬、叹，外加余味 | 爽是一种情感，不是唯一的情感；经典的深度常在"失去"里 |
| 结构 | 李渔《闲情偶寄》：立主脑、密针线、减头绪、脱窠臼 | 一个主脑（书魂＋主线）、针线要密（承诺账）、头绪要少、窠臼要脱（反默认） |
| 语言 | 冰山、潜台词、留白 | 主题不说破，只在人物的两难里演出来 |
| 判断 | 意料之外，情理之中 | 读者没猜到，回头一看前面都有铺垫 |

**AI 的默认倾向与对治**（证据见作者目录的架构审视）：把主题说破 → 书魂不进写手提示；情节整齐单线 → 场景卡要求两难与多方；事件升级平淡 → 场景卡写"风险比上一场高在哪"；人物从外部描写 → 写作简报要求从视角人物的身体写起；陈词滥调与同质化 → 作者种子、反默认、关键节拍写多版。

## 三、爽文引擎（连载的持续愉悦）

**书魂四问**：主题之问（一个没有标准答案的问题）、主角的答案（核心信念）、世界的不公（压迫答案的结构）、终局的回答。爽点是主角的答案在局部战胜了世界的不公；深度是这次胜利的代价，以及问题因此变得更难。每卷从不同角度考验同一个主题之问。

**欠·挣·超·证**：爽 ＝ 读者替主角记下的账，以挣来的方式被超额兑现，并被世界见证。缺"欠"是白给，缺"挣"是金手指代打，缺"超"是平淡，缺"证"是爽完即忘。三铁律：边际递减只能升维（个人→团队→组织→制度→文明）；欠挣守恒；见证看分量不看人数——反派不降智。

**爽感谱系**（登记爽点欠账时用 `--desire` 标编号）：1 被尊重·地位逆转｜2 公平·正义兑现｜3 变强·成长可见｜4 先知·信息差｜5 探索·奇观｜6 归属·被接纳｜7 创造·建设经营｜8 智胜·谋略｜9 守护·守住一线｜10 审美·震撼。同型连用 ≥3 就该换型。

**经典性元素**：名场面（承诺类型"名场面"，读者在等的大时刻）；核心意象 2–3 个（承诺类型"母题"，反复出现、每次带一点变化）。

## 四、世界与因果工具箱（管世界可信，不管人物鲜活）

- **四尺度**：人·群·制·天。卷级事件至少在两个尺度上可见；名场面争取四尺度贯通。
- **三时段**：长时段（地理、天道、力量体系）→ 设定；中时段（王朝兴衰、阶层流动）→ 卷纲；事件 → 章与场景。写人的选择，也写他选择时手里有什么牌。
- **八把工具**（卡住时挑一把）：第一性推演｜二阶后果（主角赢了，谁的饭碗被砸了）｜激励地图（他为什么不这么做：不能、不敢还是不想）｜约束生戏（金手指此刻能直接解决，这段还有戏吗）｜反事实检验（删掉它哪章会塌）｜以小见大｜陌生化｜矛盾转化（本卷主要矛盾解决后谁升格）。

## 五、知识入文四律

有据（场景用到的学科知识须有出处，不凭空捏造；设定可以虚构，规律不能捏造）｜冰山（学十写一）｜转化（知识必须变成冲突、选择、代价或画面）｜宁缺（拿不准的不写数字、不写术语）。

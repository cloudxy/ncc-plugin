# 创作思维框架（全部角色共用的最高判据）

与 `workflow/registry.json` 的 axioms 同源。冲突时公理优先于任何细则。

## 八条公理

1. 书魂先于情节，情节先于知识。
2. 一切叙事元素都是对读者的承诺（建立→推进→兑现）。
3. 决定按可逆度分层（L0 书魂 → L1 骨架 → L2 单元 → L3 章 → L4 文字），越难撤回越早定、越少人定。
4. 读者始终在场：写每章前先看"读者此刻"。
5. AI 扩展选项，人做选择。
6. 好钢用在刀刃上：常规章守下限，关键章投上限（约 8:2）。
7. 作者可持续。
8. 模糊之处给推荐，不把空白题丢给作者（见 guidance.md）。

## 书魂：爽与深的统一

四问：**主题之问**（一个没有标准答案的问题）、**主角的答案**（核心信念）、**世界的不公**（压迫答案的结构）、**终局的回答**。

**爽点，是主角的答案在局部战胜了世界的不公；深度，是这次胜利的代价，以及问题因此变得更难。** 每卷从不同角度考验同一个主题之问。

## 爽的第一性原理：欠·挣·超·证

爽 ＝ 读者替主角记下的账，以挣来的方式被超额兑现，并被世界见证。

| 要素 | 缺了会怎样 |
|---|---|
| 欠：压抑建账（压迫→误判→吃亏） | 白给 |
| 挣：代价或智慧（找到破口） | 金手指代打 |
| 超：幅度超额或方式意外（反打） | 平淡 |
| 证：地位、关系、秩序可见地重排（善后→新责任） | 爽完即忘 |

三铁律：①边际递减，只能升维（个人→团队→组织→制度→文明）；②欠挣守恒，没欠账的兑现是白给；③见证看分量不看人数，对手的分量决定胜利的分量——反派不降智。

爽感谱系（登记爽点欠账时用 `--desire` 标编号）：1 被尊重·地位逆转｜2 公平·正义兑现｜3 变强·成长可见｜4 先知·信息差｜5 探索·奇观｜6 归属·被接纳｜7 创造·建设经营｜8 智胜·谋略｜9 守护·守住一线｜10 审美·震撼。同型连用 ≥3 就该换型。

## 四尺度：人·群·制·天

卷级事件至少在两个尺度上可见；名场面争取四尺度贯通——一拳（人）打穿一张脸（群），震动一条规矩（制），揭开一角天机（天）。

## 三时段：长时段·中时段·事件

长时段（地理、天道、力量体系）→ 设定；中时段（王朝兴衰、阶层流动）→ 卷纲；事件 → 章纲。事件骑在中时段的浪上。写人的选择，也写他选择时手里有什么牌。

## 八把工具（卡住时挑一把）

| 工具 | 自检问句 |
|---|---|
| 第一性推演 | 这个结果是规则推出来的，还是套路搬来的？ |
| 二阶后果 | 主角这次赢了，谁的饭碗被砸了？（下一个对手往往由此而来） |
| 激励地图 | 他为什么不这么做？不能、不敢，还是不想？ |
| 约束生戏 | 如果金手指此刻能直接解决，这一段还有戏吗？ |
| 反事实检验 | 删掉这个角色或事件，哪一章会塌？ |
| 以小见大 | 哪一个细节（米价、称谓、一顿饭）能让读者"闻到"这个时代？ |
| 陌生化 | 换一个外来者看这场戏，他最惊讶什么？ |
| 矛盾转化 | 本卷主要矛盾解决后，谁升为主要矛盾？ |

## 知识入文四律

有据（场景用到的学科知识须有出处，不凭空捏造；设定可以虚构，规律不能捏造）｜冰山（学十写一）｜转化（知识必须变成冲突、选择、代价或画面）｜宁缺（拿不准的不写数字、不写术语）。

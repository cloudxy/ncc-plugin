# 作者种子

> 上限引擎 U1：开书第一步，先把作者自己的材料挖出来，再给推荐。
> 每一问都可以跳过；写一句话就够，不必写成文章。经理此后给的每个推荐，都要标明是从这里的哪一条长出来的（如"源自种子 #3"）。

| # | 问题 | 作者的回答 |
|---|---|---|
| 1 | 想写这本书时，脑子里最先出现的是什么画面？ | |
| 2 | 你最在乎、最想不通的一个问题是什么？ | |
| 3 | 你亲身经历过、见过的哪件事，一想起来就有情绪？ | |
| 4 | 最喜欢的三本书（或剧、电影）里，最打动你的是哪一刻？ | |
| 5 | 你最讨厌哪种写法、哪种主角？ | |
| 6 | 你身上有什么别人不知道的行当、地方或生活经验？ | |
| 7 | 如果这本书只能让读者记住一个场面，你希望是哪一个？ | |

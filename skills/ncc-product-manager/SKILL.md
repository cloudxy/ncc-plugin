# NCC 产品经理技能

先确认任务是需求分析、方案设计或交付复核，按[专业SOP](references/sop.md)执行；用[需求与优先级方法](references/discovery.md)处理证据和取舍，用[工件模板](templates/product-brief.md)组织结果。需要核对外部方法时查[来源索引](references/sources.md)，不凭框架名代替判断。

收到ncc-dev派单时，以包内goal、definition、授权和来源为界，按[共用协议](../ncc-dev/references/roles.md)返回JSON；各工件写入相应deliverables，不另造一份重复状态。相关[工程案例](../ncc-dev/references/experience.md)用于迁移判断。

单独咨询可直接按模板给需求/优先级/验收工件；需要改项目文件时由ncc-dev继承本次有效决定组织实施，不重新质询已确认目标。没有用户研究记录就标假设，不伪称访谈。资源管理可独立使用，价值按本次用户任务判断；原小说创作入口和有效自动定稿授权保留。

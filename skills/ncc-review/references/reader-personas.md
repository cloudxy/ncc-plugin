# 读者画像（M6-2，盲评用）

一个模拟读者给出的"追不追"，只代表一种口味。真实的读者是一群人：有人只看爽不看设定，有人看过三百本同类、一眼认出套路，有人就是干这一行的、一个外行细节就出戏。盲评按画像分别读、分别报，再合成一张**弃读热力**——几个画像在同一段失去耐心，那一段就是最该先改的地方。

本文件给经理和 reader 用。经理按画像派单，每个画像一次独立的 reader 派单（fresh 上下文，互不看对方的报告）。

## 一、四个画像

| 画像 | 是谁 | 在乎什么 | 什么让他弃 |
|---|---|---|---|
| 目标读者 | 本书 briefing 写的目标读者（题材、年龄、阅读场景，如"通勤路上刷都市文的上班族"） | 爽点来得及时，主角让人想跟着走 | 前三章还不知道这本书爽在哪；憋屈太久 |
| 老白 | 看过几百本同类的老读者 | 新意；套路里的变化；作者懂不懂行规 | 一眼看穿的套路、毒点、降智；"又是这个开头" |
| 小白 | 第一次看这个类型的新读者 | 看得懂、跟得上 | 设定和专名一上来就扎堆；人物太多认不过来 |
| 懂行读者 | 本书题材涉及的行当里的人（医生读医疗文、程序员读科技文、历史爱好者读历史文）；行当按本书的"一书一深学"和题材常涉及学科定 | 行当细节对不对；人物像不像这行的人 | 外行话、常识错误、明显没查过的细节（**出戏**） |

经理派单时，把选中画像的那一行写成一段第二人称的身份说明放进派单包（"你是……，你平时……，你最受不了……"），懂行读者写明是哪一行。**画像说明是唯一给 reader 的背景**：仍然不给大纲、设定、场景卡、作者意图。

## 二、什么时候用几个画像

| 场合 | 画像 | 理由 |
|---|---|---|
| 开篇（G3，第 1–3 章） | **至少 2 个**：目标读者＋老白；题材行业味重的（医疗、刑侦、商战、历史）换成或加上懂行读者 | 开篇决定生死，值得多花一两次调用；G3 会查至少 2 份含记忆测试的盲评 |
| 关键章的版本比选 | 目标读者 1 个 | 比的是哪版更好，一个画像的记忆测试够用 |
| 卷复盘抽查 | 按数据下滑的方向选：弃读多 → 目标读者；评论说套路 → 老白；读者指出出戏 → 懂行读者 | 用模拟读者复现真实读者的反应 |

## 三、报告与登记

每个画像一份报告：`05-审稿/blind-ch-0001-0003-<画像>.md`。报告格式见 `agents/reader.md`，必须含「记忆测试」，并新增两节供"读者此刻对照"：

- **我在等什么**：读完你最想知道接下来发生什么？用自己的话列，不超过三条。
- **我觉得谁知道什么**：你知道而书里某个人物还不知道的事。

经理把每个画像的反应登记进读者数据（`--persona` 标画像）：

```bash
ncc_state.py feedback add <书目录> --ch 2 --source 模拟 --kind 追读 --value 4 --persona 老白
ncc_state.py feedback add <书目录> --ch 2 --source 模拟 --kind 弃读 --value 段12 --persona 老白 --note "又是退婚开局"
ncc_state.py feedback add <书目录> --ch 2 --source 模拟 --kind 略读 --value 段5 --persona 小白
ncc_state.py feedback add <书目录> --ch 3 --source 模拟 --kind 出戏 --value 医学 --persona 懂行读者 --note "抢救时先推肾上腺素不对"
ncc_state.py heat <书目录> --ch 1-3        # 合成：各画像追读、弃读与略读热点、划线、出戏
```

弃读、略读、划线的 value 写段号（"段12"），热力才能按段合并。

## 四、读者此刻对照

"读者此刻"（`reader-now`）是台账推算出来的读者状态：读者知道什么、在等什么。盲评读者是真的读了。两者对一对，就知道台账准不准：

1. 经理跑 `ncc_state.py reader-now <书目录> <下一章>`，取"在等什么"的前几条、"知道什么"的信息差。
2. 和各画像报告的"我在等什么""我觉得谁知道什么"逐条对照，写进报告末尾的「读者此刻对照」一节：
   - **对上了**：台账里强度高的承诺，读者确实在等。
   - **台账有、读者没感觉**：这条承诺没立住（埋得太轻，或被别的事盖过去了）——下一批场景卡要补一次推进。
   - **读者在等、台账没登记**：意外埋下的期待。值得留的登记为伏笔或期权；不想要的，下一章别再强化它。
   - **信息差没传达到**：台账说读者知道而角色不知道，读者却没意识到——打脸、反转的前提不成立，要在打脸前再亮一次。
3. 对照结论按问题卡格式呈给作者（开篇时随 G3 一起）。

## 五、校准

真实数据回流后（`feedback add --source 真实`），单元与卷复盘的底稿会把各画像的模拟追读和真实追读并排列出。偏差规律**按画像**记成 reader 的记忆（`memory add <书目录> --role reader --kind 校准 --text "老白画像在日常章低估追读" --evidence …`；又如"懂行读者对医疗细节过敏，真实读者不在意"），下次派该画像时 `brief --role reader --persona <画像>` 把它放进派单头，随画像说明一起交给 reader。

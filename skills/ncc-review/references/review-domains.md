# 五域评审细则与报告模板

## 各域准则示例（evaluated 需带正文引用）

### 连贯逻辑（20）
- 本章事件因果可追溯（每个转折有动因）。
- 时间线与状态事件台账一致（无凭空跳变）。
- 本章设定引用与圣经/词典一致。
- 空间移动合理（对照地理距离/旅行时间）。

### 角色关系（15）
- 主角行为符合动机—行动—代价链与人物卡。
- 配角口吻区分度（对话遮名可辨）。
- 关系演变有事件支撑，不突变。
- 无 OOC：底线/恐惧/执念不无故破例。

### 情节承诺（20）
- 章纲 must-keep 逐条兑现；avoid 项未犯。
- due 伏笔已回收或显式延期（延期要有强化）。
- to_plant 伏笔按计划埋设且已登记台账。
- 词典「读者已知」栏无超前泄密（叙述视角越权）。

### 节奏爽点（15）
- 张力波峰 ≥2（指出位置）。
- 情绪点强度对锚定表（1顺带/2单章/3单元/4卷级/5名场面）。
- 章尾钩子类型与强度如实登记。
- 三维节奏（事件/情绪/篇幅）与章纲计划偏差说明。

### 文风表达（15）
- AI 味词表命中数（脚本给出基线）。
- 平均句长与对话占比在本书基准带内。
- 与文风基准校准段语感一致。
- 描写服务于情绪/信息，无炫技空转。

### 正典一致（15）
- 数值变化挂量纲（无孤数）。
- 战力表现对照换算表；越级有例外条件支撑。
- 规则表克制/兑换关系未被违反。

## 严重度定义

- **critical**：设定级矛盾、伏笔义务违约、主角 OOC、视角越权泄密 → gate blocked，必须处置。
- **major**：局部逻辑硬伤、节奏塌陷段、文风明显漂移 → 本轮修订。
- **minor**：措辞、小瑕疵 → 记录，卷末统一打磨。

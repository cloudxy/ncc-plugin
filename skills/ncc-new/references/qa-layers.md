# 三层递进问答（L1→L2→L3）

来源：chinese-novelist-skill phase1。原则：**采集成本最小化**——能从上下文推断的不问，能推荐的让作者选，能随机的给 🎲。

## 偏好记忆（{_preferences.json}）

```json
{
  "favoriteGenres": [{"name": "都市诡异", "weight": 3}],
  "preferredProtagonist": ["苟道流", "杀伐果断"],
  "preferredPerspective": "第三人称限知",
  "preferredTone": ["冷静", "黑色幽默"],
  "typicalChapterCount": [200, 400],
  "styleReferences": ["某书", "某作者"],
  "dislikes": ["圣母主角", "无脑后宫"],
  "creationHistory": [{"title": "…", "genre": "…", "at": "…"}]
}
```

- 每层答完**静默同步**；选项排序按 weight，命中偏好标 ⭐；🎲 在偏好加权后的池子里抽。
- `dislikes` 是硬约束：worldbuilder/outliner 生成方案时排除。

## L1 必答（不答不开书）

| 问 | 追问 | 落点 |
|---|---|---|
| Q1 题材 | 子类型？融合标签？（S0 已定则带出确认） | genre_tags、briefing |
| Q2 主角 | 职业/身份？性格底色？金手指或特色？ | 人物卡/主角 |
| Q3 核心冲突 | 主角和什么力量对抗？他的驱动力是什么？ | 总纲主线、premise |

## L2 可选（每题可跳过/🎲）

| 问 | 默认策略 | 条件规则 |
|---|---|---|
| Q4 世界观 | 按题材给 2–3 个方向 | 仙侠/奇幻/诡异**必答**（不给默认） |
| Q5 视角与基调 | 第三人称限知＋题材常规基调 | 群像 ambitions → 提示成本 |
| Q6 主题 | 从 Q3 冲突推导一个候选 | 可跳过（网文可后置） |
| Q7 读者与风格参考 | 偏好记忆带出⭐ | 无偏好时给大众款 |
| Q8 篇幅与特殊要求 | 200–400 章 / 3000–5000 字 | 影响大纲分卷 |

## L3 书名

- 按 `题材 → 命名映射`（都市→都市感短词、仙侠→意境词、诡异→禁忌感词…）＋至少 3 种技法（反差/悬念/身份/数字/意象）各出一候选，共 3–5 个。
- 每个候选一行说明用的技法；可整体重生成一次；超过 5 轮停止生成，请作者自拟。

## 禁止

- 不在 L2/L3 上纠缠超过两轮——未定项记「未定」继续走，worldbuilder 会显式标注并保守处理。
- 不把问答带进写作阶段。

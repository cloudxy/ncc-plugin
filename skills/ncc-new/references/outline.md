# 三级大纲与滚动窗（outliner 方法）

## 总纲.md

- 主线一句话（冲突＋主角弧光＋结局方向）。
- 分幕/分卷目录：每卷一行（阶段目标、主要对手、结束时主角状态、**本卷从哪个角度考验主题之问**）。第一卷之后的各卷可以只给 2–3 种候选走向，卷复盘时再定。
- 情绪曲线全书段：大高潮落点（约 25%/50%/75%/98%）、虐点区、爽点密度承诺。
- 结局方向（网文可以后改，但开书必须有方向，防止中期漂移）。

## 卷纲（先只做卷一）

每卷：进入状态 → 卷目标 → 钩子链（每 3–5 章一个单元钩，卷末大钩）→ 新设定引入计划（同步设定词典「首现章计划」）→ 出场人物清单 → 退出状态（主角拿到什么、失去什么）。

## 章纲

**黄金三章逐章细纲**（G2 必交）：

```markdown
# ch-0001
- 功能：开篇钩住读者（身份/危机/金手指至少占二）
- must-keep: 主角出场方式、核心悬念抛出、金手指露一角
- avoid: 大段世界观说明、超过3个新专名
- 情绪点: 悬念4 → 压抑 → 爽3
- 钩子: 悬念型, 强度4, 一句话: ____
```

**50 章滚动窗**（Openwrite 滚动规划，建筑师模式）：只为未来 ~50 章维护细章纲；写完一卷扩下一卷。混合模式只写当前单元，园丁模式不写章纲。细纲只含「必须发生的事与钩子」，不写剧情散文。

**场景卡不属于大纲期**：场景卡（`../../ncc-write/references/scene-card.md`）即写即做，只提前做到下一章；outliner 在写章循环里以 task: scene 起草。

## 承诺登记（→ 06-台账/承诺台账.json）

大纲层的伏笔、悬念、爽点欠账、人物弧、感情线、卷目标，全部用 `ncc_state.py promise add --type … --content … --ch <计划建立章> --strength 1-5 --window A-B` 登记。爽点欠账加 `--desire <谱系编号>`。写作期 writer 新建的承诺同样登记——**承诺不登记等于不存在**。

章纲里写明本章计划建立、推进、兑现哪些承诺 id；一章都没有就是计划中的水章，要么补，要么并章。

## 名场面与核心意象

- **名场面清单**：全书 5–10 个、每卷 1–3 个读者会记住的大时刻（一句话＋所在卷＋它从哪个角度考验主题之问），登记为 `promise add --type 名场面 --content … --ch <计划章> --strength 5`。写着写着冒出来的名场面随时补登。名场面所在章默认是关键章。
- **核心意象**：2–3 个反复出现的意象（一个物件、一种天气、一句话、一个地方），每次出现带一点变化，让含义一层层累积；登记为 `promise add --type 母题 --content … --ch <首次出现章>`，再次出现时 `touch`。母题不计入水章判定。

## 情绪曲线与爽点预算（pulse 的输入）

- 卷内每 10 章一段：计划爽点数、最强情绪点类型与强度。
- 连续 3 章无 ≥3 强度情绪点的区段，标「注水风险」。
- 爽点按爽感谱系轮换，同型连用不超过 2 次；卷级安排升维路线（个人→团队→组织→制度→文明）。
- 情绪不只有爽：按调色板（爽、燃、虐、甜、怕、笑、悲、敬、叹）安排，每卷至少一处让主角真正失去什么。

## G2 前自查（outliner 交货单）

- [ ] 总纲有主线一句话＋结局方向
- [ ] 卷一卷纲完整（钩子链无断档）
- [ ] 黄金三章章纲含 must-keep/avoid＋钩子设计
- [ ] 滚动窗覆盖未来 ≥ 20 章
- [ ] 大纲层承诺已入承诺台账，每条有强度与兑现窗口
- [ ] 黄金三章章纲已分配五个签约点（园丁模式在场景卡里分配）
- [ ] 名场面清单与 2–3 个核心意象已登记
- [ ] 主体性四问（`../../ncc/references/craft-canon.md` §二）：卷级大事都溯因到了具体的人；制度都落到了具体人物的处境上；代价看得见；人物选择时的约束写清了
- [ ] 每卷写明考验主题之问的角度

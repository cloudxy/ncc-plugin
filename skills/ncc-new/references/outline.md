# 三级大纲与滚动窗（outliner 方法）

## 总纲.md

- 主线一句话（冲突＋主角弧光＋结局方向）。
- 分幕/分卷目录：每卷一行（阶段目标、主要对手、结束时主角状态）。
- 情绪曲线全书段：大高潮落点（约 25%/50%/75%/98%）、虐点区、爽点密度承诺。
- 结局方向（网文可以后改，但开书必须有方向，防止中期漂移）。

## 卷纲（先只做卷一）

每卷：进入状态 → 卷目标 → 钩子链（每 3–5 章一个单元钩，卷末大钩）→ 新设定引入计划（同步设定词典「首现章计划」）→ 出场人物清单 → 退出状态（主角拿到什么、失去什么）。

## 章纲

**黄金三章逐章细纲**（G2 必交）：

```markdown
# ch-0001
- 功能：开篇钩住读者（身份/危机/金手指至少占二）
- must-keep: 主角出场方式、核心悬念抛出、金手指露一角
- avoid: 大段世界观说明、超过3个新专名
- 情绪点: 悬念4 → 压抑 → 爽3
- 钩子: 悬念型, 强度4, 一句话: ____
```

**50 章滚动窗**（Openwrite 滚动规划）：只为未来 ~50 章维护细章纲；写完一卷扩下一卷。细纲只含「必须发生的事与钩子」，不写剧情散文——留给写手临场发挥。

## 伏笔种子表（→ 06-台账/伏笔台账.json）

大纲层的每个伏笔：`{id: FS-0001, content, 预计埋设章, 预计回收窗口, status: planned}`。写作期 writer 新埋的伏笔同样登记——**伏笔不登记等于不存在**。

## 情绪曲线与爽点预算（pulse 的输入）

- 卷内每 10 章一段：计划爽点数、最强情绪点类型与强度。
- 连续 3 章无 ≥3 强度情绪点的区段，标「注水风险」。

## G2 前自查（outliner 交货单）

- [ ] 总纲有主线一句话＋结局方向
- [ ] 卷一卷纲完整（钩子链无断档）
- [ ] 黄金三章章纲含 must-keep/avoid＋钩子设计
- [ ] 滚动窗覆盖未来 ≥ 20 章
- [ ] 伏笔种子已入台账，每个有回收窗口

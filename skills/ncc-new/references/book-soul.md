# 书魂与类型契约（S0 立书，L0 层）

判据见 `../../ncc/references/mind-frame.md`；提问方式见 `../../ncc/references/guidance.md`。

## 一、类型契约

读者按类型来买某种愉悦（爽感谱系里的哪几种欲望）。立书时写明：

- **主契约**：本书主要承诺哪 1–2 种愉悦（如"凡人逆袭＋守护"）。融合题材可以有多个附加契约，但主契约只能有一个。
- **毒点清单**：违约的写法——以逆袭为主契约的书里主角长期憋屈不反击、主角降智、为推剧情让主角违背核心信念而不付代价，以及本类型读者公认的雷点。审稿查毒点；作者可以"有意为之"放行，但要写明理由并在承诺台账登记补偿。
- **签约点**（黄金三章内落地，G3 检查）：主角与欲望、世界的不公、主角的机会（金手指或独特性）、第一次小兑现、长线钩子。写章时用 `ncc_state.py sign <书目录> <签约点> --ch N` 登记。

**怎么给候选**：按已选方向，给 2–3 种主契约组合。每种写清：承诺读者的愉悦、一部对标作品、这种契约最常见的 2–3 个毒点、适合什么样的作者。推荐理由要引用本书的主角和核心冲突。

## 二、书魂四问

| 问 | 含义 | 用处 |
|---|---|---|
| 主题之问 | 全书在追问什么——一个没有标准答案的问题 | 决定每一卷考验什么 |
| 主角的答案 | 主角用行动给出的回答，即核心信念 | 决定主角在关键处怎么选 |
| 世界的不公 | 世界以什么结构压迫这个答案 | 决定压迫从哪来、反派替谁说话 |
| 终局的回答 | 主角答案的胜利、修正，或胜利的代价 | 决定暗线往哪收、结局落在哪 |

参照：《基督山伯爵》追问复仇的正当与边界，唐泰斯在清算中逐渐意识到自己不是上帝，全书落在"等待和希望"；《凡人修仙传》追问一个凡人在弱肉强食的修仙界如何活下去，韩立的答案是谨慎与隐忍，全书一次次考验这个答案。

**爽与深的统一**：爽点是主角的答案在局部战胜了世界的不公；深度是这次胜利的代价，以及问题因此变得更难。

**书魂不进写手提示**：书魂只给作者、经理、大纲、发展编辑和审稿看。写手只拿本场的两难；主题通过人物的选择演出来，不由叙述者说出来——AI 写小说的默认倾向之一就是把主题说破（StoryScope 2026）。

## 三、书魂候选怎么生成

不直接问"你的主题是什么"——没有经验的作者答不上来。按这个顺序推：

0. 先看**作者种子**，尤其第 2 条"最在乎、最想不通的问题"——它往往就是主题之问的雏形。候选要从这里长出来，并标明来源。
1. 从**核心冲突**找出主角在对抗什么（人、制度、命运、自己）。
2. 从**主角的驱动力**找出他相信什么——这是"主角的答案"的雏形。
3. 问：什么样的世界会让这个信念付出代价？——这是"世界的不公"。
4. 把"信念 vs 代价"改写成一个没有标准答案的问题——这是"主题之问"。
5. 对同一组输入，从不同角度推出 2–3 个候选（如个人与制度、个人与自己、个人与命运），每个附：
   - 四问各一句；
   - 一句"按这个写出来大概是什么样"的预览（第一卷会发生什么样的冲突）；
   - 一部公认作品参照；
   - 推荐理由（为什么最适合这本书的主角与主契约；源自哪条作者种子）。
6. 作者可以选一个、改一个、合并两个，或全部否决后自己写。**全部否决时，问一句"哪里不对"，据此再出一批，不要只删不给。**

作者仍拿不准：用推荐项标**暂定**，最晚第一卷卷复盘时定下（D7）。卷复盘会问：本卷从哪个角度考验了主题之问？主角的答案变了吗？——很多作者是写着写着才找到主题的。

## 四、写入

- 源头是 `book.json`（`soul`、`contract`、`sign` 写入）；`author-intent.md` 是由它生成的视图，给人和各角色读，不手改。
- 结构化字段：`ncc_state.py soul …`、`ncc_state.py contract …`。
- 暂定项：`ncc_state.py promise add --type 暂定决策 --content 书魂定稿 --ch 0 --deadline 第一卷卷复盘`。
- 检查：`ncc_state.py gate <书目录> soul`。

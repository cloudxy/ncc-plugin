# 素材流（M5，接地气）

本文件只管已有书项目的生活观察卡。长资料库、专题资料、原创素材的整理/完善/创建，以及开书前无 book.json 的任务，使用 [../../ncc-prepare/SKILL.md](../../ncc-prepare/SKILL.md)；需要进入某个场景的生活细节再选为本流程的素材卡。

**艺术源于生活，高于生活。** AI 写出来的东西"不接地气"，根子在它没有生活：它只有书里读来的二手经验，所以写夜班就是"疲惫地揉了揉眼睛"，写医院就是"消毒水的味道"。作者有。作者见过凌晨四点接班的人先去摸暖气片，听过陪护的人蹲在走廊里吃泡面。素材流做一件事：**把作者的生活经验记下来，在合适的场景送到写手手里。**

它和其他部件的分工：

| 部件 | 管什么 | 来源 |
|---|---|---|
| 作者种子（U1） | 开书时的七个问题：最初的画面、执念、亲历 | 开书一次 |
| **素材卡（本文件）** | 写书全程随手记的观察、经历、听来的事、行业细节 | 作者的生活，随时 |
| 知识点清单（M4） | 场景要用到的学科事实（月相、里程、火候） | scholar 查资料 |
| 拆书样本（M5-3） | 对标书里的质感细节与机制写法 | ncc-deconstruct |

素材管"真实的人和事长什么样"，知识点管"事实对不对"，拆书样本管"别人怎么写的"。

## 一、素材卡格式

一张卡一个文件：`素材/<八域>/M-NNNN-短名.md`。必填三项，其余可选（门槛低，才有人记）：

```markdown
# M-0001 夜班换岗

- 来源：亲历（作者 2019 年在物流园上夜班）
- 内容：凌晨四点换岗，接班的人不先打卡，先摸暖气片，摸完才把手套摘下来
- 可用处：底层人物的疲惫；夜班场景的质感；"冷"不用写"冷"
- 可信级：亲历
- 域：社会
- 题材：都市
```

| 字段 | 必填 | 写什么 |
|---|---|---|
| 来源 | 是 | 从哪来：亲历、谁讲的、哪篇报道、哪本书。只给审稿和作者看，不进写手包 |
| 内容 | 是 | 看到、听到、经历的具体场面。写动作、物件、原话，不写感想（"很心酸"没用，"把剩下的半个馒头揣回兜里"有用） |
| 可用处 | 是 | 可能用在什么场景、写什么人、代替什么套话 |
| 可信级 | 否 | 取值见下面的"可信级与有据律" |
| 域 | 否 | 24 张底蕴卡的学科名（社会、经济、工艺……）；决定放进哪个八域子目录，不填放 `未分/` |
| 题材 | 否 | 适合的题材标签 |

记卡：`ncc_state.py material add <书目录> --content … --source … --use … [--trust 亲历] [--domain 社会] [--genre 都市]`。作者对经理说"记一条素材：今天在医院看到……"，经理整理成三项后记卡；作者原话尽量保留在"内容"里。

**跨书共用**：作者的生活不只属于一本书。加 `--shared` 记到书库根目录 `_作者/素材/`（编号 MS-NNNN），每本书都读得到。

## 二、怎么用

1. **起头**：作者种子只记在种子文件里（写手包直接带上 #1、#3、#6），不复制成素材卡。立骨时 worldbuilder 写"社会洞察"用到的、作者讲的真实见闻，记卡。
2. **索引**：outliner 写场景卡前读 `ncc_state.py material list <书目录>`（一行一张：编号、域、可用处、内容摘要、用过没有），不读全部卡。
3. **挂到场景**：场景用得上某张素材，在场景卡里加一行 `- 素材：M-0003、MS-0002`。`scene check` 会查编号存在。
4. **进写手包**：`pack` 把挂上的素材的"内容"和"可用处"放进"可用材料"，来源不带。
5. **复盘**：单元与卷复盘底稿有"素材"一节——本段用了哪些、库里还有多少张从没用过。放久了的好素材，outliner 排下一单元时可以挑。

不为用而用：素材挂在场景上，是因为这场正好需要它，不是为了消耗库存。一张素材用好一次，胜过十张硬塞。

## 三、可信级与有据律

| 可信级 | 是什么 | 写手包里的提示 |
|---|---|---|
| 亲历 | 作者自己经历、亲眼所见 | 无 |
| 转述 | 别人讲给作者的真事 | 人名、地名和能认出本人的细节都要换掉 |
| 文献 | 报道、书、档案（来源栏写清出处） | 无 |
| 传闻 | 听说的、网上流传、无从核实的 | 只能当人物口中的说法，叙述不当事实写 |
| 拆书 | 从对标书拆出来的写法样本 | 只借写法，不搬内容 |

与 M4 的有据律一致：素材管的是质感（这件事长什么样），不是学科事实（月相、里程、火候）。素材里牵涉到具体数字、年代、工艺参数的，仍按知识点清单走 scholar。

## 四、真人真事

素材多半来自真人。**进正文之前必须脱敏**：换名字、换地方、换能认出本人的细节，保留的只是"那个场面的质感"。转述来的隐私（病、婚姻、债务）尤其小心——写手包对"转述"卡自动附提示。作者不愿意被写进书里的人和事，不记卡。

## 五、拆书样本与正向素材互校（M5-3）

ncc-deconstruct 会产出两类样本：**质感细节样本**（对标书用了哪些具体细节、起什么作用）和**机制因果链样本**（对标书写的社会规矩怎么运转）。它们和作者的正向素材互相校：

- 拆书样本告诉你"成熟作者怎么把这类细节写进戏里"，作者素材告诉你"真实的样子是什么"。
- 两者冲突时（对标书写的行业细节和作者亲历的不一样），**事实以亲历和文献为准，写法可以借对标书**；冲突本身记进素材卡的"内容"，这往往就是别的书没写出来的东西。
- 拆书样本入库时可信级记"拆书"，来源写 `拆:{书名}`，只存定位词级引用（5–15 字），不复制原文。

## 六、验收与门槛

- `ncc_state.py material check <书目录>` 校验全部卡（本书与跨书）；少于 10 张时提示作者补。素材卡不设闸门——这是作者的生活笔记，不是交作业。
- 素材卡写得太长没人看：内容一般一到三句，一张卡一个场面。

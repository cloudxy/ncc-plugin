# 交互规格模板

派单时写入对应deliverables；单独设计可保留此结构，内容按实际任务裁剪。

## 任务与主路径
使用者/入口/权限/对象范围；现有证据与假设。
入口 → 默认对象 → 用户动作 → 系统动作 → 结果 → 返回/继续位置。

## 页面与默认
入口层次、组件、字段/标签、默认范围、分页/搜索、可用动作、授权来源。

## 状态表
触发｜当前状态｜对象与内容版本｜保存/采用事实｜反馈文案｜用户动作｜下一状态｜保留数据｜焦点/返回位置。

## 恢复
人工编辑与AI并发、部分失败、取消/刷新、重试、权限不足；哪些内容保留、动作作用范围、错误指向。

## 操作验收
场景/初始数据｜操作步骤｜期望结果/内容版本｜键盘与反馈观察｜实际证据或待验｜发现及修法。

# 交互方法来源

2026-10-19核对在线原页。NCC自行编写SOP/模板，不复制组件代码，不引入上游设计系统运行依赖。

| 原始资料 | 使用与边界 |
|---|---|
| [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/) | 核对键盘、焦点、错误识别和状态信息的适用条款；记录实际覆盖，不把少量检查当整站合规结论。 |
| [W3C APG：键盘界面](https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/) | 设计复合控件时核对焦点、选择和键盘模型；原生控件优先，不强迫所有页面用自定义ARIA。 |
| [GOV.UK：错误摘要](https://design-system.service.gov.uk/components/error-summary/) | 表单校验的错误汇总、字段关联和焦点引导；NCC按场景改写文案，不复制政府服务品牌或把所有故障当表单错误。 |

WCAG固定版本为2.2，APG/设计系统为当日在线内容。需要新版本细节时重新查原页；读取/使用范围记在当次任务。集中出处见[致谢](../../../ACKNOWLEDGMENTS.md)。

# 外部来源筛查与黑名单（source vetting）

适用范围：为本书项目引入任何**外部 skill、语料、模板、工具**之前（含 ncc-deconstruct 的原著与词典导入、手动安装的第三方技能）。依据：research/15-小说创作工作流全网调研与甄别.md（Snyk ToxicSkills：36% 的 agent skill 含安全缺陷；Datadog：动态上下文命令可在防御生效前执行；Mitiga：7k 仓库中发现被劫持 base URL 与 1230+ 泄露密钥）。

## 七项检查（全过才可用）

1. **许可核对**：有明确 LICENSE 且与内容相符；AGPL 代码不得复制进本插件（只借鉴思想）。
2. **网络行为**：skill 文件内 grep `http|curl|fetch|wget|api\.|token|key`——发现外传 URL 或不明端点即拒。
3. **密钥与环境**：不读环境变量、不要求 API key、不碰 `~/.ssh`、`.env`、剪贴板。
4. **动态上下文命令**：含 hooks/dynamic context 的技能，逐行审读后再用（此类代码在模型防御前执行）。
5. **混淆检测**：base64 长串、不可读变量名、超长单行 —— 拒。
6. **指令注入扫描**：SKILL.md/README 中的"ignore previous instructions"类文本、要求把数据写到仓库外 —— 拒。
7. **语料合法性**：拆书对象必须是作者合法持有的作品；盗版书源（笔趣阁类）一律拒。

## 黑名单（按行为定罪，随时追加）

| 类别 | 判定 | 状态 |
|---|---|---|
| 含外传/混淆/密钥读取行为的 skill | 行为即罪，无论名气 | 永久 |
| 动态上下文命令类技能（未审计） | 隔离审读，审计通过前视同黑名单 | 临时 |
| 盗版书源聚合站作为"素材库" | 侵权 | 永久 |
| "AI 写小说日入 X 万"付费教程/营销号 | 营销物非方法论，常捆绑违规工具 | 永久 |
| AIGC 检测规避型"洗稿工具" | 伪装≠质量，与反AI味判据冲突 | 永久 |
| 平台 AI 功能（无训练数据退出机制核实） | 不上传未发布书稿 | 预防性 |
| 一键"人性化/去味"工具（无判据层） | 误伤修辞、夺走作者选择权 | 观念性 |

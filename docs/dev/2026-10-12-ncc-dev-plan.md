# NCC 开发入口实施计划

关联[设计](../superpowers/specs/2026-10-12-dev-workflow-design.md)和[唯一任务记录](tasks/2026-10-12-ncc-dev.md)。作者当前请求已授权按设计升级；不重复确认结构路径、项目级接入或三条任务路径。回归后规则确认、提交发布分别记录。

| 切片 | 范围与前置条件 | 验收 | 回滚/交付 |
|---|---|---|---|
| P0 | 读取设计、审查和在途改动；冻结活动仓库基线，在临时副本隔离候选 | 基线全量/一致性/生成/机械结果，任务边界 | 不改主工作树规则；保留在途文档 |
| P1 | ncc-dev 技能/命令、单一规范、commands 元数据、三个相对软链、必要说明；依赖 P0 | 正反向登记、链接定位、生成一致；局部请求和创作路由实际代理冒烟 | 仅回退本任务新增/改动路径，保留作者原改动 |
| P2 | 标准库任务证据检查器、恢复接口、真实失败用例；依赖 P1 契约 | 陈旧指纹、新文件/缺文件/执行位/删除/断链/越界/缺报告/失败状态；D3 恢复及同步变化行为 | 不建第二状态库；检查器不自动同步或发布 |
| P3 | 对确定候选跑全量、生成/一致/机械；既有 ncc-eval 两组6章×3次 fresh 盲审；开发行为、独立评审与宿主状态 | 确定性全通过；创作判据未改时允许零退化：检出/定级/结论不下降、干净章不新增 major/critical、稳定性不恶化；异常单列复核，不能调答案；作者规则确认 | 五端不可运行分别 unverified，不伪报；规则确认前不整合生效 |
| P4 | 依赖 P3 具体候选与作者确认；整合活动项目并复核最终指纹；发布另需授权 | 本地、提交、远端、消费克隆、运行逐项有依据 | 没有发布授权停本地候选；合并变更后重验；消费克隆脏不覆盖；已发布回滚按授权 revert |

仅增开发入口，不改创作阶段、闸门、角色、判据。既有用户文档改动由任务继承；所有新增开发代码/文档/接线纳入 scope。全量实际测试数由输出记载。临时评测材料只用公开合成锚定章，报告不得夹带私人内容。

验证限制：锚定章不覆盖 ncc-dev 分流/恢复；须补真实代理场景。当前 API 会话不能自动证明五端新会话加载、热更新或命令语法。独立评审遵守可用宿主授权，无能力时明确待办。开发行为评测按 skill-creator 的独立 forward-testing 在临时副本中执行，不触及主工作区或外部服务。

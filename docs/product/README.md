## 约定

- 带 `sdlc:unfilled` 的文件等于还没填。
- 只放长期事实。功能细节留在 `.sdlc/console-ui/`。
- 数据库只使用既定的 `ncc-pro` 与 `ncc-dev`。书稿与 `novels/` 不进入产品层。

# 功能地图 · NCC 创作后台

> 产品层文件（负责人：pm）。全面反映已完成实施并通过浏览器与 `ncc-dev` 集成验收的 v4 创作后台基线（截至 2026-11-25）。

## 1. 核心价值路径

```text
作者 → 登录并进入作品范围 → 在大纲/资料/市场校准方向 → 在创作台选章并勾选 AI 工序协同起草与审评 → 【Aha：采用候选或放回稿纸微调，随时导出 EPUB/TXT/MD 成稿】 → 下次或切回 CLI 工作副本时修订、设定、伏笔与待办严丝合缝
```

**核心循环：** 未确认的候选绝不替换正文；正式采用的修订、事实与审计留在同一作品范围，并与 CLI 工作副本双向幂等同步。

## 3. 关键用户旅程与验收标准

### J-1 进入作品范围与立书定调
- 已有范围时一键进入创作台；无范围时呈现引导页 `从一个故事，或一份资料开始`。
- 在 `/blueprint` 填写或编辑立书档案（书魂四问、类型契约、毒点红线、文风基准），保存后立即可在工作台查看并与 CLI `book.json` / `03-文风/文风基准.md` 同步。

### J-2 在一章内完成可拆可合的 AI 协同与专注写作
- 支持单独推演细纲、单独审评或组合起草返修；只推细纲时正文原稿绝不被覆盖。
- 开启专注模式后仅保留宋本稿纸、字数统计与退出动作（支持 `Escape` 退出）。

### J-3 大纲排布、伏笔追踪与读者此刻防剧透核查
- 细纲卡片墙与创作台顶栏共享同一章节细纲与追读钩；超期伏笔自动高亮预警。
- 切换至「读者此刻（截至第 N 章）」视角时，后端实时过滤未来章节、未埋设伏笔、暗线底牌与 `secret_note` 里层真义。

### J-4 万象设定整理、公共陈列复用与地图落点
- `/materials` 服务端多类型筛选与卡片/表格切换流畅，新建或编辑设定与 `01-设定/` 往返无损。
- `/commons` 支持按 12 板块服务端筛选，一键挂载给 AI 或克隆到当前作品。
- `/admin/maps` 支持上传安全栅格底图并在画布上直观查看与点选编辑地点坐标。

### J-5 成稿一键导出与零 UUID 团队治理
- 在 `/work` 或 `/admin/exchange` 一键导出 EPUB 3、TXT 或合稿 Markdown，支持按分卷和「仅已定稿章节」过滤，自动剔除段落注记且绝不泄露秘密内容。
- 在 `/admin/models` 通过网页受管 Device-Auth 或 HTTP 网关完成模型绑定；在 `/admin/settings` 全程免手工输入 UUID 完成建号、拉人、发令牌、归档与空空间清理。

### J-6 多视口响应式与无障碍底线
- 在 `1440×900`（桌面）、`768×1024`（平板图标轨与抽屉）、`375×812`（手机顶栏「菜单」抽屉）三档视口下均无横向溢出、全站计算字号 `≥ 12px`、正文对比度 `≥ 4.5:1`，核心保存与裁决动作均可触达。

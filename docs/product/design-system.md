# 设计系统 · 创作后台

> 产品层文件（负责人：designer）。定义 NCC 创作后台的视觉原则、品牌性格、组件规范与无障碍红线。
> 读者：frontend · qa · pm
> 现行状态（2026-11-25）：沿用深绿书案与宋本稿纸基调，不新增外部 UI 依赖或独立 token 包，全部样式令牌收敛于 `apps/management-web/src/styles/base.css`，已完成 WCAG AA 对比度（`≥ 4.5:1`）、最小字号（`≥ 12px`）及 `1440 / 768 / 375` 三档视口响应式验收。

## 1. 设计原则（用于界面取舍）

| 原则 | 意味着（do） | 不意味着（don't） | 实例 |
|---|---|---|---|
| 范围先于内容 | 顶栏先明确当前作品/资料范围，页内再展示章节或条目 | 切换范围后残留上一本书的缓存或表单 | 顶栏选作品，稿纸内选章节 |
| 裁决先于生成 | 候选分数、依据与「采用 / 放回」动作同屏并列 | 把未确认的模型输出直接覆盖进正文 | 「采用当前候选」紧邻「放入编辑器继续修改」 |
| 草稿与候选分离 | 稿纸承载作者当前输入，质量把控承载 AI 候选 | 仅推演细纲或审评时擅自改动稿纸正文 | 细纲采用只写 `beat_outline` |
| 日常聚焦、管理分组收折 | 主导航固定 6 个日常创作空间；11 个管理页按三组折叠收纳于「高级管理」 | 删除专业治理能力或改动既有管理路由地址 | 展开「高级管理」呈现世界深描、成稿与历史、空间与系统三组 |
| 人类可读优先 | 默认展示对象名称、用户名与中文状态标签，技术 ID 按需次要展示 | 要求作者手工复制粘贴 36 位 UUID 或阅读裸 JSON | 协作成员下拉选择、审计与质量页关联名称 |
| 窄屏保住写与裁决 | `768` 平板与 `375` 手机视口下保存、开始处理、导航切换均可触达且零横向溢出 | 要求手机端同时平铺桌面三栏 | `768` 收为图标轨，`≤ 640` 收为顶栏「菜单」抽屉 |
| 大胆只给专注 | 进入专注模式后隐去外围导航，只留宋本纸面、字数进度与退出 | 在不同业务页混用多套花哨皮肤 | `/work` 专注模式（支持 `Escape` 退出） |

## 2. 品牌性格与文案语气

| 是 | 不是 |
|---|---|
| 安静可靠的私人书案：克制、可核对、每次改动有据可查 | 营销着陆页、悬浮气泡轰炸、玻璃拟态或霓虹渐变 |
| 深绿标识当前焦点与主动作，暖白铺陈正文稿纸 | 低于 `12px` 的微缩说明字、浅灰洗白的正文或禁用文案 |

语气规范：短句直陈结果与下一步。「保存修订」成功即提示「新修订已保存；旧评分将重新检查有效性」。空态明确说明缺什么并给出唯一主动作按钮；错误态明确告知已输入内容是否安全保留并提供「重试」，不使用含糊的「暂无数据」「系统异常」。

## 3. 界面类型与视觉克制度

| 界面类型 | 范围 | 视觉策略 |
|---|---|---|
| 日常创作空间 | 壳层、`/work`、`/blueprint`、`/materials`、`/commons`、`/market`、`/inbox` | 克制稳重，对齐、留白与可读字号优先于装饰 |
| 签名时刻 | `/work` 专注写作模式 | 四周收起，宋本稿纸居中（最大宽 `760px`），零多余打扰 |
| 质量裁决 | `/work` 右栏「质量把控」与 `/admin/quality` | 分数、硬伤结论、维度进度条与原文证据同屏清晰可查 |
| 高级管理 | `/admin/*` 全部 11 个专业模块 | 统一遵循共享 `.plain-table`、`.scope-note`、`.perm-note` 基础样式与中文表单约束 |

## 4. 视觉语言令牌

| 类别 | 规范值 | 实现落点 |
|---|---|---|
| 颜色 | 主墨色 `#24362d`；次要文字 `--muted: #3e5147`（白底对比度 `≈ 8.2:1`）；辅助标签 `--subtle: #4a5d52`（白底与 `#f7faf8` 侧栏对比度均 `≥ 6.4:1`）；品牌主绿 `#245d4d`（配白字对比度 `≈ 7.6:1`）；侧栏底 `#f7faf8`；分割线 `#d5ddd6`；标记金 `#f3e6bd`；宋本稿纸 `#fcfdfb`；成功 `#e7f0ea / #1f4d3d`；等待 `#f8efe3 / #7a4e12`；错误 `#f8ece8 / #6a3b2a` | `apps/management-web/src/styles/base.css` |
| 字体与字号 | 界面使用系统无衬线字体，正文稿纸使用宋体衬线。页面主标题 `22px / 600`，界面正文 `14px / 1.6`，辅助说明与徽标最低 `12px / 1.5`（全站严禁 `< 12px` 字号），稿纸正文 `16px / 1.75` | `base.css` 及各特性样式表 |
| 间距与圆角 | 4px 基准网格（常用 `8 / 12 / 16 / 24px`）；卡片与分区圆角 `8px`，`1px` 实线边框，不堆叠弥散阴影 | `base.css` |
| 动效 | 仅在交互反馈时更新状态提示；遵循 `prefers-reduced-motion: reduce` 自动关闭过渡位移动画 | `base.css` |
| 响应式断点 | `1440 / 1280`：左侧栏 `228px`；`768`（`≤ 960px`）：左侧栏收敛为 `64px` 图标轨；`375`（`≤ 640px`）：左侧栏隐藏并由顶栏「菜单」按钮呼出抽屉导航，表格卡片安全折行或局部横向滚动，整页零横向溢出 | `apps/management-web/src/app/Shell.tsx` 与 `base.css` |

## 5. 核心组件契约

实现位于 `apps/management-web/src/`，保持关键无障碍名称与测试锚点稳定：

| ID | 适用位置 | 关键交互与锁定文案契约 |
|---|---|---|
| `DS-SplitScroll` | 壳层侧栏与主内容区 | 根容器保持 `split-scroll` 独立滚动，避免长文连带滚走侧栏 |
| `DS-NavDaily` | 6 个日常创作入口 | `创作台`、`大纲与暗线`、`作品资料`、`公共陈列库`、`市场与风向`、`我的待办` |
| `DS-NavAdvanced` | 折叠式「高级管理」及三组子项 | 分组小标题：`世界深描`、`成稿与历史`、`空间与系统`；展开状态与当前路由联动 |
| `DS-ScopeBar` | 顶栏范围选择、新建、快捷入口 | 默认排除已归档空间；提供 `新建作品或资料库`、`AI 配置` 及窄屏 `菜单` 按钮 |
| `DS-EmptyScope` | 零可用范围引导态 | 标题固定为 `从一个故事，或一份资料开始` |
| `DS-WorkLayout` | `/work` 三栏工作台 | 支持 `收起目录`、`收起工作舱`、`导出成稿`、`继续最近章节` |
| `DS-BeatBar` | 章节出品把控栏 | 维护章节状态（规划中/草稿/待审/已定稿）、`本章细纲`、`章尾追读钩`、`视角人物`、`所属剧情线`、`目标字数` |
| `DS-Manuscript` | 正文稿纸与专注模式 | 容器类名 `.writing-card`、编辑器 `.cm-content`、可访问名称 `编辑对象`、主动作 `保存修订`、`进入专注` / `退出专注` |
| `DS-Cockpit` | `/work` 右栏四页签 | `AI 协同`、`设定速查`、`伏笔暗线`、`质量把控`；支持 6 种工序预设与自由勾选 |
| `DS-QuickExport` | 快捷成稿导出弹窗与导出中心 | 支持 `EPUB 电子书 (.epub)`、`纯文本 (.txt)`、`合稿 Markdown (.md)`，可选分卷与 `仅导出已定稿章节` |
| `DS-FoundingCard` | `/blueprint` 立书档案 | 维护书魂四问、主角弧光、主副契约、毒点红线、写作模式与文风基准 |
| `DS-PerspectiveBar` | `/blueprint` 阅读视角切换 | 支持 `作者全知` 与 `读者此刻`（指定截止章节实时过滤剧透与里层真义） |
| `DS-SafeBasemap` | `/admin/maps` 安全底图画布 | 仅内联渲染白名单栅格图（PNG/JPEG/WebP/GIF），支持画布点击拾取坐标与视口自适应缩放 |
| `DS-ManagedOAuth` | `/admin/models` 路由与订阅面板 | 支持 HTTP API Key 与 CLI OAuth 订阅切换、受管 Device-Auth 授权码卡片与一键绑定为写作/审评模型 |

## 6. 签名时刻状态

| 时刻 | 位置 | 用户体验 | 状态 |
|---|---|---|---|
| 专注写作 | `/work` 专注模式 | 外围菜单全部退场，只剩暖白宋本稿纸、实时汉字数与目标进度，`Escape` 随时回到三栏工作台 | 已上线并验收通过 |
| 同屏质量裁决 | `/work` 右栏质量把控 | 分数、硬伤门禁、依据与「采用当前候选 / 放入编辑器继续修改」并列呈现，绝不静默覆盖原稿 | 已上线并验收通过 |

## 7. 无障碍与安全显示底线（不可妥协）

- 正文与次要说明对比度均 `≥ 4.5:1`（`--muted` 与 `--subtle` 均在白底和浅绿底实测达标）。
- 全站任何可见文字、徽标、表头与辅助说明字号均 `≥ 12px`。
- 关键交互控件触控热区与键盘焦点清晰可见（`2px #245d4d` 焦点外环）。
- 状态表达必须同时具备文字标签（如「超期未回收」「硬伤阻断」「在线」），不单靠颜色区分。
- 图标按钮与表单控件保留明确 `aria-label`（如 `编辑对象`、窄屏图标轨导航项）。
- 附件预览严格遵守后端 `X-Content-Type-Options: nosniff` 与白名单栅格校验，绝不在管理后台同源内联渲染 SVG 或 HTML。

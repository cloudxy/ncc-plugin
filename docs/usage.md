# 使用指南

第一次用先看 [README](../README.md) 的流程总览。本文回答「我想做 X，怎么说」。

## 该用哪个入口

| 你想做的事 | 这么说 |
|---|---|
| 开一本新书 | `/ncc-new` ＋ 一句话想法（信息全可跳问答） |
| 看进度 | `/ncc` 或 `/ncc status` |
| 续写 | `/ncc-write 接着写` / `/ncc continue` |
| 攒稿 | `/ncc-write 今更3章`（batch 模式分批） |
| 审某一章 | `/ncc-review 第12章` |
| 打回重写 | `/ncc-review 第3章打回重写` |
| 全书体检 | `/ncc-review 全书`（抽样＋台账体检） |
| 拆对标书 | `/ncc-deconstruct <原著路径>` |
| 改已冻结的设定 | `/ncc 把主角金手指从X改成Y`（走 revise-settings，留状态事件） |

## 场景走查

### 开书到动笔

1. `/ncc-new 都市+诡异，主角是守夜人学徒` → 快捷通道判定：题材✓主角✓冲突？缺冲突 → 只补问核心冲突一题。
2. 问答完 → worldbuilder 产设定五件套 → 经理呈示 G1：`gate check` 结果＋空白项 → 你说「冻结」。
3. outliner 产总纲/卷纲/黄金三章章纲 → G2 呈示主线一句话＋钩子链 → 你说「冻结」。
4. `/ncc-write 黄金三章` → 三章全循环（含 reader 盲评）→ G3 呈示分数与盲评 → 你说「过」→ 进入连载。

### 连载日常

- 每天一句 `/ncc-write 接着写`，循环自动走完：上下文包→草稿→机械检查→审稿→（如需）修订→复评→回写。
- 想看伏笔健康度：`/ncc status`（总/已收/超期）；`/ncc-review 全书` 出深度体检。
- 卷收官：经理提示扩卷纲＋滚动窗，pulse 出卷级节奏复盘。

### 中断与恢复

- 任何时刻断了，`/ncc continue` 从 book.json 断点续跑；writing 中断按「文件存在＋字数＋SHA」重建事实。
- book.json 万一损坏：按目录文件重建后，经理会把重建 diff 给你过目。

### 拆书喂库

- `/ncc-deconstruct ~/Documents/网文拆解/Novels/对标书.txt` → 建索引→逐章抽取（带证据与置信级）→归一→台账。
- 产出：设定词典片段（标 `拆:书名`）、伏笔手法统计、节奏基线 → 下次开书 worldbuilder 直接吸收。

## 常见问题

**为什么写手不能顺便把审稿做了？** 铁律：写者不审己稿。累加分制的前提是评审独立；自己打分必然虚高。

**为什么改一段文字也要复评？** SHA 绑定：评审结论只对评审时的正文负责。改完不复评 = 拿旧结论为新正文背书。

**问答能不能跳过？** 能。首条消息信息足够（题材＋主角＋冲突）自动跳；也可以直接 `/ncc-new 按我上次那本的套路来`（偏好记忆带出⭐默认）。

**冻结后想改设定怎么办？** 走 revise-settings：改动词入状态事件台账，受影响章节标待复评。不悄悄改——那是连续性审计的天敌。

**和 oh-story / drama-skills 什么关系？** 互不替代。ncc-workflow 管「长篇网文从 0 到连载」的完整流水线与状态账本；oh-story 偏单章写作与文风工具；拆书字段口径与《小说拆分总纲 5.0》同源，产物互通。

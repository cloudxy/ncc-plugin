# 使用指南

第一次用先看 [README](../README.md) 的流程总览。本文回答「我想做 X，怎么说」。拿不准的时候，直接对 `/ncc` 说一句话，经理会推荐下一步。

## 该用哪个入口

| 你想做的事 | 这么说 |
|---|---|
| 只有一个模糊想法 | `/ncc 我想写本书` 或 `/ncc-new ＋ 一句话` |
| 开一本新书 | `/ncc-new` ＋ 一句话想法（信息全可跳问答） |
| 看进度 | `/ncc` 或 `/ncc status` |
| 续写 | `/ncc-write 接着写` / `/ncc continue` |
| 攒稿 | `/ncc-write 今更3章`（batch 模式分批） |
| 卡文 | `/ncc 这章卡住了` |
| 感觉写偏了 | `/ncc 感觉不对劲`（对最近单元做事前复盘） |
| 审某一章 | `/ncc-review 第12章` |
| 打回重写 | `/ncc-review 第3章打回重写` |
| 全书体检 | `/ncc-review 全书`（抽样＋台账体检） |
| 拆对标书 | `/ncc-deconstruct <原著路径>` |
| 改已冻结的设定或书魂 | `/ncc 把主角金手指从X改成Y`（写变更提议，按层路由给决定人） |
| 换引导档位 | `/ncc 以后少问我` → 经理推荐切到熟手或老手 |

## 场景走查

### 开书到动笔

1. `/ncc-new 都市+诡异，主角是守夜人学徒` → 经理先问引导档位（给推荐），再问几条作者种子（最先出现的画面、最在乎的问题……都可跳过）；快捷通道判定：题材✓主角✓冲突？缺冲突 → 只补问核心冲突一题，给 3–4 个从你的种子里长出来的候选。
2. 类型契约：经理给 2–3 种主契约组合（附对标作品与典型毒点），你选一个。
3. 书魂四问：经理从你的主角和冲突推出 2–3 个主题候选，每个附一句预览；你选、改，或说"先暂定"——最晚第一卷卷复盘时再定。→ G0 书魂闸。
4. 选写作模式（默认混合）；worldbuilder 产设定五件套、人物卡与角色采访、知识台账初值，你选主角弧光 → G1：`gate check` 结果＋空白项 → 你说「冻结」。
5. outliner 产总纲（含名场面与核心意象）、卷纲与章纲（深浅随模式），承诺登记进承诺台账 → G2 → 你说「冻结」。
6. `/ncc-write 黄金三章` → 每章先写场景卡请你过目 → 关键节拍写 2–3 版，附比较与记忆测试，请你挑 → 硬伤审 → G3 呈示盲评、记忆测试与签约点 → 你说「过」→ 进入连载。

### 连载日常

- 每天一句 `/ncc-write 接着写`，循环自动走完：章节登记→场景卡→故事审→写作简报与读者此刻→草稿＋三本账回写→机械检查（含水章）→硬伤审→（如需）修订→复审→落盘。关键章（约两成，单元开始时和你一起定）多一步：你从 2–3 个版本里挑。
- 循环里遇到的小决定（审稿问题放不放行等）按推荐执行、记为暂定，每个剧情单元结束时集中给你过目。
- `/ncc status` 看承诺健康度：开放、已兑现、逾期、暂定决策与到期提醒。
- 卷收官：经理提示扩卷纲＋滚动窗，story-editor 提结构层问题，pulse 出卷级节奏复盘（完整卷复盘在 M3）。

### 中断与恢复

- 任何时刻断了，`/ncc continue` 从 book.json 断点续跑；drafting 中断按「文件存在＋字数＋SHA」重建事实。
- book.json 万一损坏：按目录文件重建后，经理会把重建 diff 给你过目。
- v0.1 建的书：经理会推荐运行 `ncc_state.py migrate`，说明改动后等你同意。

### 拆书喂库

- `/ncc-deconstruct ~/Documents/网文拆解/Novels/对标书.txt` → 建索引→逐章抽取（带证据与置信级）→归一→台账。
- 产出：设定词典片段（标 `拆:书名`）、伏笔手法统计、节奏基线 → 下次开书 worldbuilder 直接吸收。

## 常见问题

**我答不出"主题是什么"怎么办？** 不用答。经理会根据你的主角和冲突给几个候选，你挑一个标"暂定"就能开书；写到第一卷结束再定。

**什么是水章？** 两道判据：连载层面，一章既没建立、推进，也没兑现任何对读者的承诺（伏笔、悬念、爽点欠账、人物弧、感情线、卷目标、名场面），机械检查会拦下；文学层面，一章里没有任何一场发生价值翻转，故事审会拦下。

**为什么写手看不到审稿清单？** 清单一旦写进写作提示，模型就会照着清单做题，交出项项达标、整体平庸的章节。写手只拿写作简报：这场翻转什么、人物在什么两难里、读者该感到什么、一个画面、要绕开的默认写法。

**为什么审稿不打分了？** 研究表明大模型给创意写作打的绝对分和专家判断几乎不相关。现在硬伤只判通过与否；好不好看，关键章用两版对比和"读完记住了什么"来判断，最后由你挑。

**我不喜欢先写大纲怎么办？** 开书时选园丁模式：只定书魂、第一卷方向和主要人物，按场景边写边长，台账事后补记。

**为什么写手不能顺便把审稿做了？** 铁律：写者不审己稿。累加分制的前提是评审独立；自己打分必然虚高。

**为什么改一段文字也要复评？** SHA 绑定：评审结论只对评审时的正文负责。改完不复评 = 拿旧结论为新正文背书。

**机械检查没过，但我就想这么写？** 闸门可以 `--force` 放行，脚本会记下你的原话和没满足的项。审稿问题可以标"有意为之"，但要登记补偿。

**冻结后想改设定怎么办？** 写变更提议：改什么、为什么、影响哪些已发布章节、推荐怎么处置，由对应层的决定人拍板；受影响章节标待复评。不悄悄改。

**和 oh-story / drama-skills 什么关系？** 互不替代。ncc-workflow 管「长篇网文从立书到收束」的完整流程与状态账本；oh-story 偏单章写作与文风工具；拆书字段口径与《小说拆分总纲 5.0》同源，产物互通。

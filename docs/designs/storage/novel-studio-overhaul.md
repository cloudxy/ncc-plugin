# 小说创作工作台全面重构设计（出品人把控 × 可分可合 AI 协同 × 万象设定 × 公共陈列 × 市场风向）

日期：2026-11-23。状态：已实施并验收通过。前置依据：[PostgreSQL底座](postgresql-foundation.md)、[基础管理后台](management-console.md)、[创作自动化与AI评分](creation-automation.md)、[白金连载引擎方案](../writing/platinum-upgrade.md)，以及[产品层规格基线](../../product/README.md)。开源平台与方法论出处见[设计出处与致谢](../../../ACKNOWLEDGMENTS.md#开源小说创作工作台与-sdlc-优势融合2026-11-23)。

## 1. 背景与核心设计转向

原管理后台（v4 初版）已打通 PostgreSQL 实体/版本/事实底座与基础评分能力，但信息架构呈“数据库治理台”形态：侧栏平铺 14 项菜单，创作台缺少卷章树、大纲细纲卡片与伏笔暗线视野，AI 流程仅支持整包黑盒生成或单独评分，无法满足长篇小说创作习惯。

本轮重构围绕**“人作出品人把控（审核、引导、指引：方向把控、内容把控、质量把控），AI 作可分可合的协同班底”**全面调整前后端与界面布局：

1. **极简六维主导航 + 折叠式高级管理**：
   - 主导航聚焦创作者高频空间：**创作台（`/work`）**、**大纲与暗线（`/blueprint`）**、**作品资料 / 万象设定（`/materials`）**、**公共陈列库（`/commons`）**、**市场与风向（`/market`）**、**我的待办（`/inbox`）**。
   - 原 11 项数据治理与系统管理入口（定义中心、身份与历史维护、关系与时间、地图与地点、质量与评分、导入与导出、任务中心、操作审计、成员与设置、AI 配置、运行管理）完整保留原路径兼容，默认收折于「高级管理」分组下，日常写作零噪音。
2. **三栏可折叠创作书案 + 一键专注模式（`/work`）**：
   - **左栏（卷章与细纲目录树）**：支持「分卷 → 章节」层级展示、按状态/剧情线/关键章轻量聚合筛选、上移/下移调序、一键新建卷章、显示字数与状态。
   - **中栏（出品人章节顶栏 + 宋本稿纸 + 专注模式）**：顶部可折叠维护本章细纲（`beat_outline`）、章尾追读钩（`hook`）、视角人物（`pov`）、所属剧情线（`plotline`）与目标字数（`target_words`）；中部为沉浸稿纸，支持一键开启**专注模式**（隐去外围导航与侧栏，仅留纯净纸面与字数进度）。
   - **右栏（四合一出品人工作舱）**：同屏切换 **AI 协同**、**设定速查**、**伏笔暗线**、**质量把控**，彻底解决写长章时上下反复滚屏与跳页查资料的割裂感。
3. **可单独拆分、可自由合并的五段式 AI 创作流水线**：
   - 将创作过程解耦为五个标准工序：`plan`（细纲节拍推演）→ `judge_plan`（P2 故事结构审校）→ `write`（正文起草/选段扩写）→ `judge`（品质分项与硬伤独立审评）→ `revise`（按批注/问题自动返修）。
   - 支持**单工序独立执行**（如仅推细纲、仅按已确认细纲写正文、仅审评、仅按出品人指引返修）与**多工序合并连贯执行**（如「细纲+结构审」「起草+审评+自动返修」「全流程一条龙」）。细纲成果采用时直接回写章节 `beat_outline` 而不误覆盖已有正文。
4. **大纲、细纲卡片墙与伏笔暗线看板（`/blueprint`）**：
   - 统一承载总纲与剧情走向、章节细纲索引卡片墙（Corkboard）及**明线 / 暗线 / 灰线**伏笔看板，支持按分卷、剧情线、线索层级与兑现状态轻量聚合与排序，自动标示临期与超期未回收伏笔。
5. **万象设定集与深度人物角色馆（`/materials`）**：
   - 原生支持人物角色（动机、恐惧、人物弧光、心理侧写、阵营关系、语言风格）及跨流派创作要素（场景、地图、特效、技能、功法、丹药、妖兽、魔兽、异世界生物、都市、现代武器、法师、亡灵、鬼、魔、异族人、拍卖会等），提供领域胶囊聚合、卡片墙/表格双视图与多维排序。
6. **跨书「公共陈列库」（`/commons`）**：
   - 面向所有小说复用的公共知识与技法陈列馆，覆盖 **12 大板块**：写作套路、人物描摹、剧情走向、人物弧光、心理分析、关系分析、哲学思考、管理、财务、技术、艺术、环境。内置精选创作母本图谱，并打通作者跨书公共资料库（`author` / `research` / `universe` 范围），支持跨范围授权注入 AI 上下文或一键克隆入书。
7. **「市场与风向」监控与指导模块（`/market`）**：
   - 集成起点白金赛道母本库（核心爽感公式、3·10·30 三级火箭配速、五类追读钩配比、30 万字中期陷阱、致命毒点红线）、市场对标观察笔记与本书连载节奏实时诊断（总字数、均章字数、关键章占比、活跃暗线 5 条锁池预警、超期伏笔告警）。

## 2. 架构与数据边界

- **零物理表结构变更**：复用既有 `ncc_scope`、`ncc_definition`、`ncc_entity`、`ncc_revision`、`ncc_fact`、`ncc_job`、`ncc_assessment` 表，不新增 Alembic DDL 迁移，严格遵守 `ncc-pro` / `ncc-dev` 双库约束。
- **评分策略哈希稳定**：`src/ncc_shared/quality/resources/policy.json` 保持原字节不变，已有评分记录、校准与自动定稿授权完全兼容。
- **动态属性无损演进**：在 `src/ncc_data/domain/definitions.py` 扩展创作属性与跨流派系统类型，并在系统定义读取与种子初始化层无损补齐缺失属性键，使既有数据库无需清库即可直接使用细纲、钩子、弧光、心理分析与关键章标记。
- **跨范围只读引用安全**：AI 任务包读取 `commons_refs` 时逐项校验操作者对目标公共范围的 `read`（及 `secret`）权限，且仅作为参考上下文注入，不混入当前书事实写回白名单。

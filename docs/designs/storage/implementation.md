## 实施顺序

1. **环境与数据契约**：新增独立Python包/依赖及Alembic迁移，PostgreSQL私有作用域、身份、定义、对象、修订、时态事实、关系、审计、幂等和任务。领域名词通过16领域种子定义承接。真实书库不自动迁移。
2. **统一应用服务**：范围授权、版本化草稿/预检/采用、动态值约束、历史和分支、关系与组织、叙事/认知/证据、精确数量、来源附件、质量问题及查询；API/CLI/Worker共用事务和业务规则。
3. **自动化与评分**：P1–P5固定量表、证据验证、确定性汇总、严重硬伤/维度/过期阻断、作者选择与托管边界；持久生成/评价/返修步骤、有限预算、取消接管及模型适配。无校准数据不得宣称自动定稿已获验证。
4. **FastAPI与React后台**：同源会话/CSRF/权限、三个创作入口、动态专业资料维护、关系/时间/地图/文本、变更/导入导出/任务/审计/运行管理；实际接口联通，空/错/冲突状态可操作。
5. **旧工作流接入与数据交换**：保留标准库文件模式；数据库模式显式选择，经统一服务读写并受版本保护。影子导入保留原件、映射与未知字段、预检及回执；完整导出和恢复工具不把派生视图变为事实源。
6. **验证与交付**：全量原CLI回归及注册表/插件一致性；真实临时PostgreSQL的并发、权限、时态、幂等、任务和导入恢复；前端类型检查/构建及浏览器操作；记录实际结果、模型/校准/独立评审/五端加载缺项。更新使用说明及版本，按当前授权交付本地候选，不顺带提交推送。

## 回退与权限边界

代码和规则按小批次推进，评分规则先在隔离合成样例验证。默认文件书项目保持原运行路径；只有显式切换的范围使用数据库，不进行双主写入。任何真实范围切换前先完成影子对账和恢复演练；切换后回退必须包含最新数据完整导出。API无自动建库/迁移、匿名管理员或任意SQL/脚本执行入口。临时验证服务只用于合成数据，结束时停止。

新服务依赖独立于原CLI，依赖锁文件在实际解析后生成。自动评分输出为模型评估而非读者实测；测试用合成Provider的运行证据与真实模型效果分别记录，不伪造后者。当前请求授权实施，不隐含外部发布、真实书稿上传或真实数据清除。

现有 index/mark/coverage/stats/link 入口保留，新增 plan/packet/ingest 与按层参数；规范化实现位于 scripts/ncclib/deconstruction。真实拆书项目仍在私有书库，插件升级不自动重新切章、迁移或重派正在执行的批次。机器字段表见[有限结构契约](contracts.md)；落点依据见[架构成长方案](../engineering/architecture-growth.md)。代码已合入本地工作树与功能验收完成分别记录。

## 一、问题与目标

现行拆书以总纲 5.0 逐章抽取为主，缺少按研究目的和书长调节工作量的路由。长篇全量叠加卡片、剧本、人物事件和技法，成本过高；多卷重起章号、无号引子、重复标题、同号分章又会让索引失败。章文件解析、别名、类型和定位词缺少统一的入库闸门，进度与实际产物也可能脱节。

升级目标是先得到可信索引和骨架，再按目标选章深拆，把场次作为技法层的附加产物，最后按需将已有结论转化为写作参考。总纲 5.0 的事实、证据、置信级、事件溯源和设定分类继续有效；不要求每个研究任务都做完整逐章卡片。

| 当前能力与缺口 | 本次设计落点 |
|---|---|
| 已有索引、手动标进度、覆盖率和基线统计 | 索引分级诊断；按层进度；入库验证后才记完成 |
| 当前索引把全书章号重号、跳号、短章一并视为问题 | 区分原书编号异常和切片不可用，连续 `seq` 作为唯一引用 |
| 技能要求跨章三件套，脚本尚无统一派单/章文件入库接口 | 新增派单与入库契约，验证上下文来源、章 hash 和产物 |
| 已有统计先检查覆盖率 | 保留闸门，补抽样与连续范围的统计边界，防止样本冒充全书 |
| 尚无插件内剧本场次台账 | 增加可选 `screenplay`，不改变作者自己的场景卡契约 |
| 已有技法卡与写作侧引用 | 场次到方法再到写作参考，保留两处证据与失效条件 |

不做全书自动剧本、对白本、外部工作流安装器或自动续写；不把对标书人物、事件链和场次直接写入作者大纲。外部项目仅提供可选方法参考，不进入受管依赖、打包和必需运行链。

## 二、按目标分层

| 层 | 输入和处理 | 产物与边界 |
|---|---|---|
| L0 索引 | 原文、卷标和可核对的标题规则；机械切片 | 唯一章节索引、编号异常、正文 span/hash；所有模式必做 |
| L1 骨架 | 索引、字数与对话标记等机械数据、已存在且有来源的概括 | 卷/章结构、每百章字数与对话比例；人物、事件和爽点只在有语义证据时写，不能由机械计数推断 |
| L2 技法 | 选定章节、总纲 5.0 抽取、跨章上下文 | 事实卡、状态台账、场次、质感/机制样本、技法卡；默认只深拆关键章 |
| L3 转化 | 已验收的骨架、技法和场次报告 | 方法模块、适用条件、代价与本书可选用法；不重新读取原文全文，不生成本书正文 |

| 作者目标 | 默认执行 | 完成含义 |
|---|---|---|
| 看懂结构 | L0 → L1 | 骨架报告完成，不称全书逐章已拆 |
| 研究写法 | L0 → L1 → L2 关键章 | 样本计划完成，报告写出取样范围和缺项 |
| 拆完用于创作 | 已有 L1/L2 → L3 | 可写方法供 outliner 选择；新书立项与创作仍走原入口 |
| 完整逐章拆解 | 作者明确选择后，L0 → 全章 5.0 抽取；场次另行选范围 | 保留旧用途；预算确认后才能全书展开场次 |

关键章默认由三组构成：开篇前 10 章、按全书八等分位置选取的 7 个内部抽样章、结局后 10 章，去重后按 `seq` 排序。不足 20 章时开篇/结局允许重叠；内部抽样位置用 `1 + round(k × (N - 1) / 8)`（k = 1…7），算法与取整规则写进计划以便重跑。作者可以增补卷末、转折或特定问题章节，每项记录理由。长篇默认深拆上限是这个显式集合，而非一个含糊的书长阈值。

取样计划保存在拆书库中，记录目标、层、选中 `seq`、分组理由、索引指纹和允许的统计。缺任何一组显示未完成或有理由地豁免；未选章节不写成“跳过”，不计入全书已拆。L1 无现成人物事件概括时标缺项；若目标需要补充，单列经批准的语义阅读范围与成本，不隐藏为全书抽取。

## 三、索引唯一真源与异常分级

继续由 `decon index` 生成 `索引/chapter_index.json`。`seq` 按正文文件顺序连续递增；原文章号 `no` 保留原值，另记 `volume`、同号分章标记 `part`、原始标题、起止行、字数和正文 hash。无卷标时 `volume` 为空；无号序章的 `no` 为 0，其他无法确定的编号为空，不伪造原文章号。

标题识别默认匹配整行章题，顶格优先。先识别卷边界，再识别章题；允许文件级标题缩进配置，不以“行内出现第 N 章”作为切分依据。同题缩进回声只有在标题相邻、间隔不超过三行且其间无正文时才忽略；相邻顶格完全同题也按此条件折叠。上、中、下等有区别的分章不合并。无正文的卷/篇名只作为元数据或问题记录，不占章节序号。

| 情况 | 处理 |
|---|---|
| 两卷都从第一章开始 | 合法，按卷记录原号，`seq` 连续 |
| 独立整行的序、引子、楔子、序章且有正文 | 收入索引，原号 0；后接第一章不算跳号 |
| 原书章号跳号、同号上中下分章 | 收入索引并记录 warning；缺的原号不生成假章节 |
| 短章、有正文的特殊序章 | 记录短章 warning，不仅凭少于 100 字判空章 |
| 同卷、同号、同题隔正文再次出现，且不是明确分章 | blocker，核对是真重复内容还是两个不同章节 |
| 无章题、切片重叠、零正文章、卷边界无法区分的重号 | blocker；修标题规则或提供书级显式覆盖配置后重建 |
| 明确站点广告、目录回声或空篇名 | 按可解释规则排除并记录；不做大段静默删文 |

warnings 不阻止可用索引落盘；blockers 不允许进入抽取。`--force` 不再作为绕过结构错误的通用解法；保留参数兼容时也须对未解决 blocker 失败。人工核对通过书级配置记录理由和具体边界，不能靠全局忽略重号。索引记录原文 hash、规则版本、诊断分类及配置来源。

卷与戏剧幕分开：`volume` 是原书卷名，不自动等于 `act`。如需戏剧分幕，书级索引附加 `act_ranges`（按 `seq` 区间与来源说明）；没有分幕时 `screenplay.act` 为空。

原文或切片规则变化后重建索引，对照旧 `seq`、span、hash 列出影响。`seq` 移动时不自动沿用进度；只有核对原文一致和引用映射后才能迁移。正在运行的库外试点保持原索引，待批次结束后生成对账报告，不中途覆盖。

## 四、派单、入库与断点恢复

### 派单包

L2 每章包包含本章索引/span/hash、层和范围、总纲路径、适用词表、前情摘要、活跃实体 ID/别名、未回收伏笔、可选幕区间来源。三件套必须有内容或明确的空集合及依据；缺文件或未知不得伪装为空。首章可为空，标记初始化来源。

非连续抽样不能把上一抽样章当作紧接本章的前情。优先读有来源的段落摘要与已有台账，并标注中间未审范围；没有可靠上下文则阻塞依赖跨章指代/伏笔的抽取，或明确降级为章内独立分析、不进入跨章事实台账。为补上下文扩大阅读范围时单列成本，不隐含逐章扫全书。

包的指纹绑定索引、章 hash、上下文来源和词表版本。已有实体使用库内 ID，新实体待归一分配；长章分块传递已抽实体清单。本章成果不能反向进入自己的前情包。

### 入库闸门

1. 文件层：标准库 JSON 解析、根对象/必填结构、章号与 hash、派单包指纹、所需三件套有效性。解析错误或契约错配整章阻塞，保留错误原因，不能记 `done`；不默默修逗号后当作原始结果通过。
2. 条目层：校验 5–15 字定位词在本章正文、置信级与类型词表、实体引用、量纲和别名证据。坏事实进入丢弃/待校验台账并说明原因，其余有效事实可入库。若缺失必需产物或全章条目均失败，标记待修复；纯交代章明确声明无该类事实，可有合法空数组。
3. 场次层：L2 计划要求场次时，验证 `screenplay` 及每场证据；无有效场次不得标记场次完成。5.0 基础事实完成与场次完成分别记账。
4. 提交层：章文件和规范化条目先写临时文件并校验，再原子替换；以章节 hash、层和条目 ID 幂等更新台账，最后写进度。中断后能从已验收章文件重建派生台账，不能重复追加。文件写入成功但进度未写时，续跑重新校验后补记。

别名只合并专名及原文明示同指的称呼；“又称、又名、绰号、就是”等是证据例子，不是唯一合法句式。女尸、山神等描述性称呼不进入自动别名映射；无法确认的“胡爷”一类称谓保留待校验，不靠字面判断合并。别名指向冲突保留证据，禁止先到先得。

力量源改为可缺省的状态事件，不把实体底卡上的空值当冲突。后章明确变化记录状态变迁；同章明确多种力量可以并存。只有对同一时点、同一属性给出互不相容断言才登记冲突，不静默丢后值。旧实体底卡保留为历史初始值，迁移时不臆造状态或证据。

### 进度

`_progress.json` 增加版本、索引指纹、各层计划/完成/失败/豁免、章 hash、产物指纹和错误摘要。每章验收入库后立刻更新，不等一批结束；重跑同章不重复记完成。恢复先核对索引、包和产物，再补缺项或失败项，不能只凭“文件存在”跳过。

旧 `done/skipped` 保留读取兼容，映射为 legacy 5.0 覆盖，不能证明新增校验或场次完成。历史已拆章可显式重新校验升级状态，不强制重抽整库。手动 `decon mark --done` 对新契约章必须先验产物；旧库的手动标记只算 legacy 状态，不能绕过新层闸门。

## 五、剧本场次与写作转化

章 JSON 保留 5.0 字段，附加 `screenplay: {act, logline, scenes}`。`logline` 用自己的话写本章戏剧任务；地点、时间或戏剧任务显著变化时分场，纯交代可压成一场。没有把握的内容留空或待校验，不能为了填字段编转折。

| 场次字段 | 约束 |
|---|---|
| `scene_id`、`chapter`、`order` | 稳定 ID、索引 `seq`、章内顺序 |
| `slugline`、`int_ext`、`place`、`time_of_day` | 场头、内/外景、地点与时间；原文不明时允许空并说明 |
| `characters` | 在场实体 ID 或尚待归一的引用 |
| `objective`、`obstacle`、`turn`、`outcome` | 目标、阻碍、翻转、落点；不适用可空并记原因，交代场写明交代任务 |
| `actions`、`dialogue` | 动作概括最多 4 条；对白意图最多 6 条，含说话人、意图、潜台词与定位词；潜台词不明留空 |
| `locator`、`confidence` | 本章 5–15 字证据与置信级；不同推断可逐字段附证据 |

归一后写 `剧本/场次.jsonl`（一行一场）和章内人读版“剧本”节。自写概括与对白意图的连续原文重合超过 15 字拒绝；定位词作为受限证据字段单独校验。复用现有技法卡查重机制时要核对其接口，不假设已有场次校验函数。

| 拆书字段 | 可供 outliner 参考的写作字段 |
|---|---|
| objective / obstacle / turn | 目标 / 阻碍 / 翻转 |
| characters | 在场人物参考，不自动建本书人物卡 |
| slugline / act | 留在对标报告，不自动变成本书场头或幕界 |

参照导出只放拆书库 `报告/对标场景卡/`，标明“对标参照”，不进入作者的 `02-大纲/场景卡/`，不参与本书 `scene check`，不替代 story-editor 审核。

学法只读已验收台账、场次和报告。相同方法至少两处证据才成为技法卡，一处仍是样本；写清适用条件、代价与失效。抽样任务不必等待连续 30–50 章，但要满足计划覆盖和两处证据，结论限定在样本；完整拆解沿用按段/卷汇总。

L3 输入清单只允许已落盘报告、技法与场次产物及其指纹；不把原文路径交给转化执行者。输出抽象手法模块与选择建议，不搬运原书事件链。选择落地到作者自己的书后，仍由 outliner 规划、story-editor 审故事、writer 按本书写作包写稿。

## 六、覆盖率与统计口径

| 口径 | 闸门与允许输出 |
|---|---|
| 全书机械骨架 | 原文与索引有效，可给字数/卷章结构/对话比例等；机械比例写明口径，不称语义质量分 |
| 全书 5.0 基线 | 保留原覆盖率核对；新增字段覆盖、丢弃和显式跳过披露。关键台账缺数据时该指标为不可计算，不能给“零” |
| 连续范围基线 | `--range A-B` 核对该范围及需用的前置状态；只声称本范围结果 |
| 非连续样本技法 | 只给样本章数、分组覆盖、场次覆盖、样本内分布与方法，不给全书爽点密度或最长连续压抑 |
| 伏笔超期 | 仅在连续观察覆盖充分、伏笔有初始状态且观察截至点明确时计算；样本间未读区域不能判疑似遗忘 |

`索引章数 = 已拆 + 显式跳过` 仍是账目覆盖条件，不是数据完整性的证明。显式跳过/丢弃影响某指标时披露不可计算或局限；不能为了完成计划批量把未选章节记为跳过。局部范围中在边界前埋下的伏笔没有前置状态时，等待时长留空。

统计新增计划范围、已验收章数、有效场次章数、总场数、平均场数、条目丢弃数及指标可用性。旧库无 `screenplay` 时原统计数字保持旧口径，新增场次字段标“未采集”，不能推成 0 场。部分/抽样结果另存范围报告，不覆盖原全书 `报告/基线.json`；`decon link` 使用的仍是带明确范围和口径的基线，只作参照。

已接入子接口：`decon plan` 生成/查看目标与选章集合，`decon packet` 组装章节包，`decon ingest` 验收并入库，`decon coverage --layer …` 查层覆盖。`index / mark / coverage / stats / link` 旧入口保留；新索引把原号跳号/短章降为警告，范围报告另存且不覆盖全书基线，这是本方案明确的行为变更。参数、有限结构契约和错误码见字段说明及技能参考；本地实现不等于测试已经通过。

P1 的契约交付需逐项列字段类型、必填/可空、默认值、允许枚举或 registry 引用、版本、示例、错误归类及兼容策略。只承诺标准库实现的有限结构契约，不宣称支持完整 JSON Schema；证据定位、指纹、幂等和跨章关系由运行校验函数承担，不能靠字段表代替。提供最小正常对象及缺字段、错类型、旧版本、错 hash、包错配等反例；在 P1 的隔离候选中实现足以校验样例的最小结构验证与字段表生成，不提前实现索引/入库业务。每条设计约束能对应到校验用例或行为样例后才冻结，后续 P2–P5 按冻结接口补实现。

参考拆分同步登记经理与 deconstructor 的全部可能读取文件，load_budget 保持按角色累计的保守上限。四种目标的实际读取与停止边界仍须作者行为验证，不以拆文件或静态预算代替。当前实现使用 scripts/tests 的样例归属与 registry 分片源。

新增数据带 schema/version 与索引/产物指纹；迁移为显式操作，先生成差异清单，再由用户按范围选择。外部工具能读 ncc 索引或报告则作可选适配，不能另外生成一份被当作真源的章节序号；外部工具拒绝异常编号时记录原因，不强行覆盖 ncc 索引。

## 九、关键验收矩阵

| 场景 | 预期 |
|---|---|
| 序 + 两卷重起号 + 同号上下 + 编号缺口 | 索引连续 `seq`，原号与卷名保留；缺口和分章可查 |
| 缩进/相邻标题回声、空篇名、真实重复章 | 仅无正文回声折叠；真实重复阻塞；不靠 `--force` 全放行 |
| 标题有统一缩进、正文中提到“第 N 章” | 配置后识别真实标题，正文提及不切章 |
| JSON 少逗号、hash/包错配、引用不存在实体 | 文件级阻塞或条目级拒绝按契约区分；进度不会伪完成 |
| 无证据别名、词表外情绪、定位词不在正文 | 坏条目记录原因；有效事实保留，必要产物缺失标待修 |
| 力量源空值、跨章变化、明确同时多源、同点矛盾 | 前三者不丢弃，只有矛盾进入冲突待校验 |
| 非连续样本无前情、缺别名/伏笔文件 | 不伪造三件套，不把前一抽样章当紧邻前情 |
| 各写入点中断、重复同章入库、原文变更移号 | 恢复可重建无重复；旧 hash/错位引用不能沿用完成 |
| 研究一千余章长篇 | 只计划骨架与默认关键章；未选章不记跳过或已拆 |
| 场次缺转折、证据不实、意图复抄原句 | 不编转折；不合格场次不得完成；重合超限被拒 |
| 覆盖不足、连续段有缺章、稀疏抽样 | 不能给虚假的全书密度、连续压抑或伏笔遗忘结论 |
| 旧单卷/旧库无场次 | 旧入口与旧口径可读，新增层显式未采集，升级验收单列 |
| 转化与参照导出 | 只读已验报告，输出留在拆书库；不写作者大纲或正文 |

## 十、取舍、风险与待决定项

推荐采用“可信索引与入库先行，按目标分层，场次按计划附加”。全本同时跑三套工作流的方案成本不受控；只延长技法卡不能对应一场戏；直接合并对标场次到本书场景卡会污染创作承诺；用 `--force` 吞结构错误会扩散到所有引用，因此均不采用。

主要风险及处置：标题规则可能误切，用可解释书级配置和 span/hash 样例核对；严格别名可能暂时分裂实体，保留待校验证据而不猜合并；稀疏抽样的跨章解释不足，明确降低结论范围或增加有预算的补读；字段过多诱发编造，允许不适用/未知；新进度与旧库不兼容，保留 legacy 读取和显式迁移。只生成报告的原始库不自动升级。

作者本轮已明确要求完成 P1–P6 的代码功能模块，继承此前“测试单独进行”的安排；实现、测试代码和接线按该范围交付。P6 的实际回归验收与规则确认保持待办，旧架构的通过记录不能证明本次功能。提交/推送和其他机器同步另按授权处理。

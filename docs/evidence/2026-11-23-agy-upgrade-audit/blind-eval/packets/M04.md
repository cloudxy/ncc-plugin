# 第十章 宵禁

南巷口火把噼啪作响，黑衣陈捕头的刀锋已抵在药箱铜扣上，沉声喝道：“戌时三刻已过，奉命盘查宵禁，搜他药箱！”

两名皂隶上前一步封住退路。沈砚解下回春堂的夜行腰牌递过去：“差爷明鉴，小人是回春堂学徒，赶往城西刘宅送急症汤药。”

陈捕头接过腰牌，就着火光对了一眼腰间更筹，反手便将木牌扣入掌中：“牌子上写明戌时三刻前通行，如今已是戌时四刻，逾时作废。连人带箱押回衙门，明日辰时再审！”

从南巷口走到城西刘宅还要两刻钟，一旦进衙门，今晚定然误事。陈捕头已经挑开箱盖，用刀鞘拨开上层纱布，翻出箱底那半截磨损的枣木断尺，放在火把下敲了敲尺背的寸刻与旧木茬，见只是寻常木工量材的旧尺，便随手丢回箱角，伸手要去扣药盒。

若不开盒自证急症重药，今晚休想脱身；可一旦见风动刀，这支三年赤参便要折去三成药力，诊金也得大减。沈砚不再犹豫，掀开木盒，抽出药刀当面切下赤参主根一角，浓郁参香混着盒底应急止血散的气味顿时散开：“城西刘老爷心脉急症全指望这支赤参吊命，文书就在盒盖内侧。差爷若执意扣药押人，万一亥时前刘宅出了人命，回春堂与南城捕班谁担这桩干系？”

陈捕头凑近验过新鲜参茬与刘宅求药红帖，脸色微变。他自然不肯替富户暴毙背这口黑锅，权衡片刻，将腰牌揣进怀里冷声道：“腰牌本捕头先扣下留底。药你送去，明日辰时带回春堂掌柜亲笔回执来衙门领牌销案，若有半句虚言，两罪并罚！”

刀锋收回鞘中，皂隶让开巷道。沈砚合紧药箱抱拳行礼，快步没入风雪夜色。

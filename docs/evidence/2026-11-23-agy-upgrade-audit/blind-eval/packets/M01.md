# 第九章 夜探西院

子时的梆子刚响过两声，西院账房的窗纸里还透着豆大的烛火。门廊下站着六名佩刀护院，按时辰守在院门两侧。

沈砚推开虚掩的房门走了进去。坐在太师椅上的赵管事明明手里紧攥着传唤护院的铜哨，抬眼扫了一下赤手空拳的记名学徒沈砚，却忽然冷笑一声，推窗挥手把门外六名护院全赶去后山巡夜，还主动从暗格里取出那本记录贪墨铁证的真账拍在桌上：“账本就在这儿，借你翻两页又何妨，量你一个杂役也翻不出花来！”

说完，赵管事竟背过身去慢条斯理地拨弄炭盆，连桌角都没再看一眼。沈砚连袖中的铁片都没用上，怀里的凝血散也原封未动，顺手拿起那册真账揣入怀中，毫发无损地推门走出了西院。夜风吹过长街，身后连半声哨响都没有。

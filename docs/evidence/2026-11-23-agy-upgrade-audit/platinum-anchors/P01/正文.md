# 第八章 晨粥

次日清晨，外门膳堂的木桶刚揭开盖，熬得稀薄的黄米粥热气腾腾地扑出来，混着灶房昨夜没烧透的湿柴烟味。排在前面的两个杂役弟子缩着脖子搓手，小声抱怨今年的冬菜腌得太咸，连喝三碗水都压不下去。打饭的胖火工敲了敲铜勺，催促后面的人把木碗递快些，别堵着风口散了热气。沈砚端着粗陶碗排在队伍末尾，慢吞吞地喝完半碗热粥，又顺手把碗筷放回竹筐，沿着石板路不紧不慢地往外走，听着路边麻雀在枯枝上扑棱积雪。

至于昨晚石室里那场剑抵咽喉的虚惊，早已被他抛在脑后。

走出膳堂一盏茶工夫，他拐进僻静的竹林，把湿透的旧外袍塞进枯井石缝里，迎着寒风打了个哆嗦，总算抹掉了衣角沾上的痕迹。再走一刻钟，百草圃的篱笆门已经出现在晨雾里，早课钟声刚刚敲响，巡查弟子并未来得及盘问他。

沈砚蹲到药架旁整理药篓，手指探入竹篾夹层，摩挲着那块焦黑木牌——旁人只当它是北境驿卒的寻常火牌，实则它正是前朝镇北军的虎符母印，只要日后合上副印便能调动三万边军铁骑。他不动声色地把木牌按回原处，提起水瓢走向田垄。

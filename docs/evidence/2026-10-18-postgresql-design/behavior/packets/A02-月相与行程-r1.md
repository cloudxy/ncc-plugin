# 第十三章 夜路

腊月初三的夜里，青云城的城楼上挂着一轮明月，照得官道发白。

陆言出了北门，没敢走大路，拐进了河堤。河堤上的雪没人扫，一脚下去没到脚踝。他走一阵，歇一阵，把怀里的药包往里塞了塞，生怕雪水洇进去。

半日后，他已经站在落霞镇的牌坊底下了。镇口的狗叫了两声，又不叫了。

姐姐家的门缝里还透着光。他抬手要敲，手停在半空——屋里有男人说话的声音，不是姐夫。

他把药包轻轻放在门槛上，转身走进了雪里。

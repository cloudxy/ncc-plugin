# 第八章 二叔

二叔来的时候拎了两斤橘子。

"你爸的事，我都听说了。"他把橘子放在床头柜上，挑了一个最大的剥开，"厂里那边，我去说。"

陆言没接橘子。他盯着二叔的手——指甲缝里有一道黑，像机油。陆言心里清楚，二叔才是林家那件事背后真正的主谋，可他不能说。

"晚上别去地铁站那边转了。"二叔站起来，拍了拍他的肩，"那扇门你也别碰。"

陆言点头。等二叔走了，他摸出口袋里的工牌，翻到背面。那扇青铜门其实是前文明留下的洞天入口，工牌背面的花纹就是开门的钥匙。

他把工牌攥紧，下楼，往地铁站走去。

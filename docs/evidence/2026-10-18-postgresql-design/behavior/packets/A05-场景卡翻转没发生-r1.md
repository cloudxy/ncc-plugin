# 第五章 工牌

保安亭的窗户上结了一层雾。陆言敲了三下，里面的人才把窗推开一条缝。

"我来拿我爸的工牌。"

"什么工牌？"保安队长嘴里叼着烟，"厂里的东西，丢了就是丢了。"

"有人看见在你抽屉里。"

队长把烟拿下来，在窗台上按灭，看了他很久。"小孩，"他说，"你爸还想不想在这儿干了？"

陆言站在雨里，没说话。身后排队打卡的工人越来越多，有人在笑。

他把手插进兜里，转身走了。走出很远，他才发现自己一直攥着拳头。

# 第十二章 当铺

雨停的时候，陆言才走到城南的当铺。

柜台比他的胸口还高。掌柜的从高处探出半张脸，眼皮也没抬："当什么？"

陆言把包袱解开，里面是一块旧玉佩，边上磕掉了一个角。"这是我令尊留下的，当五两。"

掌柜把玉佩捏起来，对着门口的光转了一圈，又看了看手表，说："快打烊了，二两，不当就走。"

陆言没动。这块玉值多少，他心里有数，掌柜心里也有数。可家里的药钱拖不过今晚。

"三两。"他说，"再加一句话：明天这个时辰，我来赎。"

掌柜笑了一声，把玉佩扔进抽屉，数出三两碎银推过来。"明天这个时辰，"他说，"它就姓周了。"

陆言把银子攥在手心里，攥得生疼。他转身出门，没回头。

# 第十四章 回城

第三天傍晚，陆言才望见青云城的城墙。

西天挂着一弯月牙，细得像指甲掐出来的印子，没等他走到城门口，就沉到城墙后头去了。城门还没关。

守门的老兵认得他，抬了抬下巴："药送到了？"

"送到了。"陆言说。他没提姐姐家门缝里的那个声音。

老兵往他身后看了一眼，雪地上只有一行脚印。"一个人走三天，"他说，"你爹当年也这么走过。"

陆言停了一下。"他走去哪儿？"

老兵却不说了，把城门推开半扇，让他进去。

# 锚定章（评测用）

每个目录是一章锚定章：一段像真书一样的正文，加上审稿时会拿到的材料，以及答案。`scripts/ncc_eval.py` 用它们量审稿的检出率、误报和稳定性（见 `skills/ncc-eval/SKILL.md`）。

| 文件 | 内容 | 进派单包吗 |
|---|---|---|
| `正文.md` | 锚定章正文（原创，几百字即可） | 进 |
| `场景卡.md` | 本章场景卡 | 进 |
| `台账.md` | 审稿需要的台账摘录：时代背景、视角、知情台账、知识台账、设定词典、承诺义务 | 进 |
| `知识点.md` | 本章知识点清单（可选） | 进 |
| `answers.json` | 答案 | **不进** |

`answers.json`：

```json
{
  "id": "A02-月相与行程",
  "suite": "底蕴",
  "era": "古代",
  "verdict": "fail",
  "mech": ["月相与日期"],
  "expected": [
    {"id": "d1", "category": "底蕴", "severity": "major", "quotes": ["挂着一轮明月"], "desc": "腊月初三不会有满月"},
    {"id": "d2", "category": "连贯逻辑", "severity": "major", "quotes": ["半日后，他已经站在落霞镇的牌坊底下", "半日后"],
     "keywords": [], "desc": "知识台账记三日，正文半日走到"}
  ]
}
```

- `suite`：底蕴、连贯、承诺、对照（干净章）。
- `verdict`：这章应判通过（pass）还是不通过（fail）。干净对照章写 pass、`expected` 为空，并加 `"mech_clean": true`（机械层也不该报底蕴提醒）。
- `mech`：`check_chapter.py` 应该给出的提醒（取提醒文字里的关键词）；没有可机检的错就留空。
- `quotes`：能定位这处错的原文片段，审稿报告的"正文引用"与其中任一段重合即算检出；`keywords`：错在"缺了什么"（如翻转没发生）、没法靠引文定位时，用问题描述里必须出现的词来匹配。

**写锚定章的规矩**：正文原创，不摘任何真书；一章只埋一两处错，埋在审稿真正容易漏的地方；**干净对照章要真的干净**——写完逐句核一遍（月相、行程、称谓、视角），对照章被判出问题，要先怀疑是不是自己埋了错。
